## 摘要
从分子结构预测嗅觉品质是化学信息学中的一个开放问题。尽管线性模型能够将分子特征与气味描述符关联起来，但在外推到新的化学骨架、极端分子量或复杂气味混合物时，它们常常失效。为解决这一问题，我们提出了GraphNOSE，一个开源的图Transformer框架，能够从简化分子输入行输入系统（SMILES）字符串预测单分子和二元混合物的多标签气味描述符。通过将位置编码和结构编码集成到基于Transformer的图架构中，GraphNOSE以比标准图神经网络（GNN）基线少六倍的参数取得了强劲性能，同时在平均受试者工作特征曲线下面积（AUROC）上持续优于线性模型、分子语言模型嵌入、分子指纹和基线GNN，平均提升4.52%（p < 0.01）。GraphNOSE在分布外（OOD）化合物上实现了84%的AUROC，超过了当前嗅觉OOD最先进的GNN（Open-POM：81%，p < 0.001），并识别出了线性模型经验性失效的条件。最后，我们应用可解释人工智能（XAI）方法来识别哪些子结构和分子特征驱动气味预测，所得结果与化学直觉一致，并基于模型学习到的表示而具有合理性。综合来看，这些结果确立了GraphNOSE作为一种可扩展且可解释的嗅觉预测架构，能够泛化到当前感知数据库中代表性不足的结构性不同化合物。

## Abstract
Predicting olfactory qualities from molecular structure is an open problem in chemoinformatics. Although linear models can link molecular features to odor descriptors, they often fail when extrapolating to novel chemical scaffolds, extreme molecular weights, or complex odor mixtures. To address this, we introduce GraphNOSE, an open-source graph transformer framework that predicts multi-label odor descriptors from simplified molecular-input line-entry system (SMILES) strings for single molecules and binary mixtures. By integrating positional and structural encodings within a transformer-based graph architecture, GraphNOSE achieves strong performance with six times fewer parameters than standard graph neural network (GNN) baseline while consistently outperforming linear models, molecular language model embeddings, molecular fingerprints, and baseline GNNs by an average area under the ROC curve (AUROC) margin of 4.52% (p < 0.01). GraphNOSE achieves an AUROC of 84% on out-of-distribution compounds (OODs). This exceeds the current state-of-the-art GNN for OOD in olfaction (Open-POM: 81%, p < 0.001), and identifies conditions under which linear models empirically fail. Finally, we apply XAI (explainable AI) methods to identify which substructures and molecular features drive odor predictions, yielding insights consistent with chemical intuition and grounded in the model's learned representations. Together, these results establish GraphNOSE as a scalable and interpretable architecture for olfactory prediction that generalizes to structurally distinct compounds underrepresented in current perceptual databases.

## 一、论文的核心问题与整体含义（研究动机与背景）

气味预测是化学信息学中一项长期存在的开放难题。尽管结构相似的分子可能引发完全不同的气味感知，而结构迥异的分子也可能呈现相似气味，这种“结构—感知”之间的非线性脱节是领域内的核心挑战。该论文正是针对这一问题展开研究，其背景要点如下：

- **现有方法的瓶颈**：线性模型虽然可以将分子特征映射到气味描述符，但在面临**结构新颖的化学骨架、极端分子量、以及训练集中未出现过的气味混合物**时，性能会明显退化，泛化能力不足。
- **数据层面困难**：公共嗅觉数据库往往规模小，且标注稀疏不一致；气味标签缺乏标准统一，描述符间存在高度不平衡，且缺少强度上下文等信息。
- **MPNN/GNN的局限性**：消息传递类神经网络有效捕捉局部化学环境，但受限于感受野，难以对远距离依赖建立全局关系——而气味感知往往取决于分子整体的几何与拓扑特征，而非孤立官能团。
- **图Transformer尚未引入嗅觉预测**：全局注意力机制能够一步关联分子中的任意两个原子，具备建模整体结构的能力，但在该论文之前，图Transformer尚未被应用于结构—气味预测任务。
- **核心提出的方案**：GraphNOSE——一个开源、参数高效的图Transformer框架，从SMILES字符串直接预测**单分子与二元混合物**的多标签气味描述符，并兼顾可扩展性、泛化能力与可解释性。

## 二、论文提出的方法论

### 核心思想

GraphNOSE建立在 **GraphGPS（General, Powerful and Scalable architecture）** 框架之上，将**局部消息传递**与**全局自注意力**并行融合，并利用**预训练的位置/结构编码（GPSE）** 增强分子拓扑与几何信息的表征能力。模型采用多标签分类策略，以端到端方式对分子图进行气味描述符预测。

### 关键技术细节

- **分子图构建**：基于RDKit与DeepChem，用自定义featurizer把SMILES转化为无向图。节点为原子（92维原子属性），边为化学键（7维键属性），特征包括原子序数、价态、形式电荷、杂化方式、芳香性、键级等。
- **混合架构（GPS层）** ：每一层并行两条通路——
  - **局部MPNN分支**（GINE消息传递）：专注于官能团和近邻交互；
  - **全局注意力分支**：建模分子内长程依赖与整体拓扑。

  两分支特征相加后经MLP更新节点表示，形式化描述：

  ```
  X_(ℓ+1) = GPS_ℓ(X_ℓ, E, A)
  ```

  其中 MPNN 分支显式使用边特征，全局注意力作用于节点嵌入。模型整体含4层GPS，隐层维度64，节点经均值池化后送入512维MLP分类器，输出138个气味标签的概率。

- **双注意力变体**：
  - `GraphNOSE_lin`：线性Transformer（Performer），复杂度线性；
  - `GraphNOSE_trans`：标准自注意力，复杂度二次方。

- **位置与结构编码（PSE）**：在手写编码（RWSE、LapPE）之外，重点引入 **GPSE（Graph Positional and Structural Encoder）**——一种预训练的自监督图编码器，其潜在表征可作为节点增强特征。预训练语料包括 MolPCBA、ZINC、ChEMBL、GEOM、PCQM4Mv2 等数据集。GPSE参数冻结，特征经MLP投影后与原子特征拼接。

### 训练与损失

- **数据集划分**：80:20训练/测试，训练内部再留20%做验证；使用**迭代分层抽样**保持标签分布。
- **类别不均衡处理**：对每个气味描述符按频率倒数加权二元交叉熵损失。
- **优化器与调参**：Adam优化器，初始学习率 6.82×10⁻⁴，batch size 16，最多150 epochs；超参数经Optuna贝叶斯优化。
- **统计检验**：种子配对的配对t检验比较模型性能差异，并计算Cohen's d效应量。

## 六、主要结论与发现

1. **PSE选择**：GPSE显著优于手写的RWSE和LapPE编码，且GPSE对预训练语料的选择不敏感；MolPCBA语料在数值上最优，推测与其生物活性标注与嗅觉受体机制的潜在一致性有关。该数据已被认定为最终配置。
2. **主基准（单分子）** ：GraphNOSE_lin 以89.02%的宏AUROC达到最佳成绩，显著高于OpenPOM（87.14%，p = 0.0028）、LDM_GCN（86.91%，p < 0.001）、LDM_DMPNN（86.60%，p < 0.001）；相比最强线性基线高出4.26%；而模型仅用314K参数（约为OpenPOM 2M参数的1/6）。
3. **低数据场景**：在30%–50%训练数据区间，GraphNOSE的性能优势最大，表明在小样本条件下数据效率较高。
4. **极端OOD**：GraphNOSE_lin 在物化性质偏移最严重的35%分子上实现84.26%的AUROC，较OpenPOM 的80.84%显著提升（p < 0.001），较最强线性模型LR (MACCS) 高出约5.8%。
5. **嵌入空间质量**：GraphNOSE的隐空间在KNN检索中表现出比Morgan指纹更强地捕获感知相似性的能力（86.91% vs 79.73%），KDE可视化进一步证明其同时保留大类分离与亚层级结构。
6. **二元混合物**：GraphNOSE_lin 以77.96%的AUROC显著优于Sisson等人的MPNN基线76.64%（p = 0.0083），同时使用281K参数，远低于MPNN的2M。
7. **可解释性**：Integrated Gradients 显示模型高度关注符合化学直觉的关键官能团，例如醇类为羟基、酚类为酚羟基、硫类为硫原子、酮类为羰基、水果类指向酯基等。

## 七、优点

- **模型设计新颖且具有明确需求驱动**：将图Transformer首次引入嗅觉任务，打破了此前MPNN独占的局面，针对嗅觉任务对全局拓扑感知的真实需求进行了有效验证。
- **参数效率高**：用314K参数在多个基准上超越2M参数的基线，呈现优异的精度—参数权衡。
- **泛化验证较为系统**：涵盖标准划分、极端物化OOD划分、低数据采样三大场景，并通过结构不相交的划分验证混合物泛化，实验设计思维较为全面。
- **PSE消融富有指导意义**：对GPSE与RWSE/LapPE以及5种预训练语料的系统性对比，填补了PSE选择方面尚无指导原则的空白。
- **多重验证维度相辅相成**：从预测准确度（高AUROC）、空间表征质量（KNN/KDE）、到模型解释（Integrated Gradients）三个层次统一验证模型的合理性。
- **对比充分**：基线覆盖面广，从简单线性模型到语言模型再到量子增强GNN和专属优化模型均有纳入，且共享数据划分避免评估偏差。
- **可复现性好**：代码、数据划分、脚本全部开源公开。

## 八、不足与局限

- **立体化学信息缺失**：由于采用的是非异构SMILES输入，模型无法区分**对映异构体**——对映异构体可能具有明显不同气味，但模型会输出相同预测。
- **缺乏浓度效应建模**：气味质量不是静态属性，会随浓度改变而改变（如furanol从草莓味变为焦糖味），静态的二元标签本质上无法表达这种动态性；论文虽然指出该问题，但仅在总结中提及而未提供解决方案。
- **超参数敏感**：论文自述模型对超参数设置有一定敏感性，但未提供详细的稳定性测试区间，实际复现时对调参经验的要求较高。
- **单一数据集依赖**：所有评测基于GS-LF一种数据集，尽管已是领域最大的基准之一，但缺乏跨多个嗅觉数据库的验证，对于标签噪声与标注不一致的鲁棒性未能得到充分检验。论文也自述需要对更大、更多样化的数据做未来验证。
- **混合物泛化范围有限**：只验证了**二元混合物**及有限描述符集合，未扩展到三元及以上的复杂气味混合物场景，结论的生态效度存在限度。
- **线性注意力与标准注意力的差异有待更充分的探讨**：虽然Performer在多数条件下与标准注意力差异微小，但在RWSE上出现了性能分化，且论文并未从理论角度深入展开解释该现象的机制。
- **算力透明度不足**：未披露模型训练的具体硬件配置与时间，计算成本的可评估性较差。
- **可解释性分析为定性判断**：Integrated Gradients结果的解释主要基于化学直觉的定性验证，缺乏与人类感知行为数据的定量对齐指标。
