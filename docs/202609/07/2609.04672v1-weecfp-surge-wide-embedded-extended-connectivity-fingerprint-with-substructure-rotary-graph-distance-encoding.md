## 摘要
我们引入了WEECFP，一种无参数的1024维连续分子指纹，它将每个Morgan子结构散布到单个向量的大约三十二个带符号位置上；以及WEECFP-SuRGE，一种Transformer架构，其自注意力将SuRGE（子结构旋转图距离编码）——一种由分子最短路径图距离参数化的类RoPE旋转——应用于WEECFP子结构标记。该架构的7模型集成（WEECFP-SuRGE集成）在TDC ADMET排行榜上取得了最低的平均回归排名；在TDC ADMET排行榜上整体排名第2（仅次于预训练的MapLight+GNN），并且在不使用外部预训练的方法中整体排名第1；在完整的22项基准套件中，于Pgp、亲脂性、CYP2D6底物、微粒体清除率和LD50上取得排行榜第1名（WEECFP-NoSuRGE集成在HIA上单独达到第1名）——全程无任何外部预训练。在MoleculeNet上，WEECFP-SuRGE在4项回归任务（ESOL、亲脂性、QM9）中的3项上击败了所有经典指纹基线。我们进一步证明，WEECFP的标记化几乎是无损的：一种贪婪重叠重建能够恢复9个MoleculeNet数据集中99.9%的分布内分子的精确规范SMILES，以及跨数据集留存集（HIV->亲脂性）中98.93%的分子；并且，一种三参考最远优先的图距离编码与真实成对距离的Pearson相关系数r=0.901，从而在匹配精度下实现了O(S)的位置记忆。

## Abstract
We introduce WEECFP, a parameter-free 1024-dimensional continuous molecular fingerprint that scatters each Morgan substructure across roughly thirty-two signed positions of a single vector, and WEECFP-SuRGE, a transformer architecture whose self-attention applies SuRGE (Substructure Rotary Graph-distance Encoding) -- a RoPE-like rotation parameterized by molecular shortest-path graph distance -- to WEECFP substructure tokens. A 7-model blend of this architecture (the WEECFP-SuRGE Blend) achieves the lowest average regression rank on the TDC ADMET leaderboard; is #2 overall on the TDC ADMET leaderboard (behind only pretrained MapLight+GNN), and is #1 overall among methods that use no external pretraining; takes leaderboard #1 finishes on Pgp, Lipophilicity, CYP2D6 Substrate, Clearance Microsome, and LD50 (with the WEECFP-NoSuRGE Blend separately reaching #1 on HIA) across the full 22-benchmark suite -- without any external pretraining. On MoleculeNet, WEECFP-SuRGE beats every classical-fingerprint baseline on 3 of 4 regression tasks (ESOL, Lipophilicity, QM9). We further show that WEECFP tokenization is near-lossless: a greedy overlap reconstruction recovers the exact canonical SMILES of 99.9% of in-distribution molecules across 9 MoleculeNet datasets and 98.93% of molecules in a cross-dataset holdout (HIV->Lipophilicity), and that a three-reference farthest-first encoding of graph distance correlates at Pearson r = 0.901 with the true pairwise distance, enabling O(S) positional memory at matching accuracy.

- **背景**：计算分子性质预测是虚拟筛选、ADMET 分析、先导化合物优化的核心工具。现有方法主要有两大流派：
  - **经典哈希圆形指纹**（如 ECFP/Morgan），将 Morgan 子结构哈希为单个比特。这类指纹与梯度提升树搭配效果好，但与神经网络结合时存在本质缺陷：二元向量只占据超立方体角落，维度全开或全关，缺乏梯度下降可用的幅度信息；同时缺少子结构间的拓扑位置关系。
  - **预训练图神经网络与分子 Transformer**（如 Chemprop、MoLFormer、Graphormer 等），通常依赖大规模外部预训练，训练成本高，且其精度优势相对轻量模型并不总是显著。
- **核心问题**：能否在不依赖任何外部预训练的前提下，设计一种同时具备以下能力的分子表示与架构——
  1. 对神经网络友好（连续值、含幅度信息）；
  2. 保留每个子结构的独立身份信息（而非单比特哈希混淆）；
  3. 显式注入子结构之间的分子拓扑距离（图距离），以捕捉性质预测中关键的几何/拓扑信号。
- **整体含义**：论文提出了一条"经典指纹的确定性先验＋轻量 Transformer 从零训练"的中间路线，挑战"必须依靠大规模预训练才能达到 SOTA"的主流范式，为无预训练分子性质预测设立了新的性能标杆。

## 2. 方法论：核心思想与技术细节

整个流程包含三个组件：**WEECFP 连续指纹**、**SuRGE 图距离旋转编码**、以及二者结合而成的 **WEECFP-SuRGE Transformer**。

### 2.1 WEECFP-S 指纹（广嵌入扩展连通性指纹）

- **指导思想**：沿用 ECFP 的 Morgan 圆形子结构枚举逻辑，但将"每子结构置 1 位"改为"每子结构散射至约 32 个带符号的连续位置"，生成连续的、确定性的、参数自由的 1024 维向量。
- **Morgan 枚举**：利用 RDKit 的 Morgan 指纹（bitInfo），枚举每个 (原子, 半径) 对产生的唯一子结构 ID，半径默认 R=2。
- **每个子结构的写入方式（三块信息）**：
  - **块 1（子结构哈希散射）**：对 Morgan ID 取两个 MD5 摘要（h₁ 与 h₂），每个字节同时决定目标位置和带符号值。例如：
    - h₁：pᵢ = (bᵢ₊₁₇ · i) mod 1024，vᵢ = (bᵢ ≫ 4) − 8⁸⁻ᵢ 的整数映射，每条写入约 16 个位置；
    - h₂ 使用步长 31 和低半字节，再贡献约 16 个写入；
    - 合计每子结构约 32 次带符号写入。关键是"同字节定位置和符号"，使两个不同子结构在同一位置碰撞时符号倾向相反而形成结构化的抵消（而非简单叠加干扰）。
  - **块 2（原子性质）**：中心原子的 7 个标量性质（原子序数 Z、度、氢数、芳香性、环成员、形式电荷、键级和）写入由元素特定偏移确定的连续位置（(7Z) mod 512 起）。
  - **块 3（邻键信息，半径 r≥1）**：每个成键邻居贡献 8 次步长 23 的哈希写入（键类型决定）和 8 次步长 29 的哈希写入（邻居原子序数决定），与块 1 位置不相交。
- **压缩与聚合**：每子结构向量先做对数幅度压缩保持方向性（f ← f·ln(1+‖f‖)/‖f‖），再按分子求和为最终的 WEECFP-S 指纹。结果是每分子约 89% 稀疏的 1024 维连续向量，生成速度约 1 ms/分子（单 CPU 核）。
- **WEECFP 与 WEECFP-Scatter 的区别**：若每子结构向量不求和而作为独立 token 输入 Transformer，则称 WEECFP；若只用块 1 的散射（无原子性质和邻键块），则称 WEECFP-Scatter（消融对照）。
- **近无损可逆性**：尽管单次写入有损，但由于子结构在库中的确定性编码，可通过贪心重叠合并重建出精确的规范 SMILES——分布内 99.9%、跨数据 98.93% 的重建率（所有失败仅因立体化学注释差异）。说明该编码承载了近乎完整的子结构身份信息。

### 2.2 SuRGE：子结构旋转图距离编码

- **核心思想**：将 LLM 中 RoPE（旋转位置编码）的"序列位置"替换为"分子最短路径图距离"，使注意力机制能感知子结构在分子中的拓扑相对位置。
- **Token 化**：每个 Morgan 子结构 (v, r) 作为一个 token，其根原子 v 用于查询 BFS 距离矩阵 D 中任意两 token 之间的图距离。序列截断至 300 个 token，前置可学习的 [CLS]。
- **两种位置方案**：
  1. **Mean-distance（md）**：每个 token 取到其他所有原子的平均图距离 pᵢ = (T−1)⁻¹∑ⱼ d(vᵢ,vⱼ)，外围子结构位置值更大。这种方案仅保留径向位置信息（中心性）。
  2. **Three-reference（ref3）**：用最远优先遍历选 3 个参考原子 r₁、r₂、r₃（第一个最小化平均距离，后续最大化到已有参考集的距离）。每个 token 编码为 3 维向量 [d(vᵢ,r₁), d(vᵢ,r₂), d(vᵢ,r₃)]，避免了 md 方案将拓扑压成一维标量导致的信息丢失。
- **SuRGE 旋转**：与 RoPE 完全相同，按维度对将嵌入旋转 φₖ = s·pᵢ·θₖ（θₖ = base^(−2k/d)，base=100000，位置尺度 s=2.0）。对 ref3，维度对 k 轮流使用 pᵢ[k mod 3] 作为相位，即不同维度对被分配给不同参考方向。
- **两种应用位置**：
  - **Input SuRGE**：只在输入投影后旋转一次，后续层不再旋转，计算开销减半；
  - **Layer SuRGE（默认）**：在每一层注意力内按 RoPE 规范方式旋转（keys/queries 各自先旋转再运算），能保持各深度距离信号。
- **O(S) 可扩展性论证**：论文从理论推导上证明，原始"成对距离旋转"需要存储 B×H×S×S×(d_head/2) 的张量，复杂度 O(S²)（S=1000 时约 7.8 GB/层）；而 ref3 编码将每个 key 仅旋转一次，存储为 O(S)（S=1000 时约 16 MB），在 S=1000 时约有 4 万倍以上的内存缩减。三参考编码与真实两两距离的 Pearson 相关系数 r=0.901。
- **对 CNN 禁用 SuRGE 的理由**：若在 1D 膨胀 CNN 的 token 嵌入上按位置旋转会破坏卷积的平移等变性——同一子结构在不同序列位置会产生不同特征模式，固定卷积核无法复用。经验上，移除 SuRGE 在 22 个 TDC 基准中的 20 个上改善了 WEECFP-CNN 的表现。

### 2.3 模型与集成

- **主干网络**：3 层 pre-norm Transformer，d_model=256，8 头注意力，FFN 宽度 512，输入投影为 Linear→LayerNorm→GELU→Dropout（将 1024 维 WEECFP token 映射至模型维度），预测头为 LayerNorm→Linear→GELU→Dropout→Linear（取 [CLS]）。
- **训练设置**：AdamW（weight decay 1e-4）、基础学习率 2e-4 余弦退火、最多 150 个 epoch（早停 patience 15）、batch size 32、梯度裁剪范数 1.0；回归用 z-score 归一化目标上的 MSE，分类用 BCEWithLogits。
- **7 模型集成（WEECFP-SuRGE Blend）**：集合了 3 种骨干（Transformer / CNN / MLP）× 2 种 token 方案（WEECFP / Morgan）× 是否拼接 Avalon+ErG 增强特征（+AE），共 7 个模型，取逐 seed 预测的算术平均。集成成员搭配设计考虑多样性，组合在评估 TDC 测试集之前即固定，未做按任务的择优选择。

- **额外专项实验**：重建实验（9 数据集分布内 300 分子/集 + 跨数据 HIV→Lipophilicity 4200 分子）、图距离编码相关性实验（2925 分子）、内存扩展性理论 + 数值验证（S=50–1000）、SuRGE 可逆性数值验证、Oracle 子集搜索诊断。
- **消融层次**：表征（块 1/2/3、WEECFP vs. Scatter）、位置编码（md/ref3/无、Input/Layer）、架构（Transformer/CNN/MLP、SuRGE 有无）、数据增强（AE 有无）、集成（7→单模型、SuRGE→NoSuRGE）、骨架切分种子稳定性。

### 5.2 充分性与公平性评价

- **优点**：对比基线覆盖面广（含 10 种经典指纹×2 模型）、同时报告了 leaderboard 原始排名和无预训练方法的细分排名、给出了完整的消融链条以隔离各组件贡献、按官方协议与固定种子评估，整体实验设计相当严谨。
- **可能不足**：
  - TDC 排行榜对比中，"#1 NoPT"的统计口径为论文自行划分，且某些对比方法（如 CFA、ZairaChem）的实现细节未在同一框架内复现，跨论文数字比较存在实现差异风险；
  - 分类任务上相对预训练方法差距较大，归因分析仍偏定性；
  - 预训练/无预训练的分类并不完全等价于"公平比较"——无预训练的对比方法本身超参选择与调优程度可能参差不齐；
  - 部分关键结果（如 ESOL 上 no-r0 表现最佳）依赖于小数据集，稳定性待验证——文中给了 5 seeds 均值和方差，但个别对比差距较小时没有显著性检验。

## 6. 主要结论与发现

1. **TDC ADMET 榜单位置**：
   - 7 模型 WEECFP-SuRGE Blend 在 9 个回归任务上平均排名 3.9，为所有提交方法（含预训练的 MapLight+GNN 5.3、MiniMol 6.4）中最低；
   - 全 22 个基准上整体平均排名 5.1，位列第 2（仅次于预训练的 MapLight+GNN 4.3），在所有无外部预训练方法中排名第 1；
   - 取得 5 个排行榜第 1（Pgp、Lipophilicity、CYP2D6 Substrate、Clearance Microsome、LD50）；NoSuRGE Blend 另在 HIA 上单独第 1。
2. **MoleculeNet**：在 4 项回归任务中的 3 项（ESOL、Lipophilicity、QM9）超过全部 12×2 经典指纹基线；FreeSolv 上 XGB+MACCS 仍为最优。
3. **SuRGE 的具体贡献**：
   - 相比无 SuRGE 对照（no-r2），Lipophilicity RMSE 从 0.719 降到 0.706，QM9 从 0.872 降到 0.842（ref3）；
   - 移除所有 Transformer 中 SuRGE 的 NoSuRGE Blend 平均回归排名从 3.9 退到 4.1，整体从 5.1 退到 5.3（排名第 4），证实 SuRGE 是回归优势的主要来源；
   - SuRGE 在子结构多样性大的数据集上增益明显，但在极小数据集（ESOL 1128 分子）上原子级特征（no-r0）反而最好。
4. **WEECFP 优于二元指纹**：MLP+WEECFP-S 在 ESOL、FreeSolv、Lipophilicity 上均超过 XGB+WEECFP-S，优于所有经典二元指纹基线的 MLP 搭配——验证了连续值、带符号的表示对神经网络的可学习性优势。
5. **近无损可逆性**：WEECFP 子结构编码支持贪心重建，分布内精确 SMILES 恢复率 99.9%、跨数据 98.93%（失败全部为立体化学差异）；说明该编码信息密度高，可审计性强。
6. **线性位置记忆**：三参考编码距离相关 r=0.901，匹配全成对 SuRGE 的精度但位置状态记忆从 O(S²) 降为 O(S)（S=1000 时约 977 倍缩减）。

## 7. 优点与亮点

- **方法原创性**：首次系统性地将 RoPE 的旋转位置编码思想推广到分子图距离，提出 SuRGE——填补了"经典指纹缺乏位置表征"与"图 Transformer 依赖注意力偏置/预训练"之间的空白。
- **架构简洁免预训练**：以无参数的确定性指纹 token 取代学习式嵌入，3 层小 Transformer 从零训练即可达到/超越预训练大模型在回归任务的精度，成本极低、可

成本极低、可复制性强——这让高精度 ADMET 预测不再被锁定在大规模预训练基础设施中。
- **无监督增强的可选择性与可解释性**：融合 Avalon/ErG 仅在最终集成中选用，且论文以 Oracle 子集搜索证明这种辅助特征对单模型的收益并非稳定，体现了对复杂集成技巧的审慎态度，而非盲目堆砌。
- **深入的负结果分析**：论文不回避"SuRGE 在 CNN 中整体有害"、"小数据集上无位置编码反而最优"、以及"MLP 在某些任务上不输 Transformer"等不利于主线叙事的结果，并给出了机制层面上的解释；在数据集规模分布、模型等变性、网络容量与信号丰富度之间建立起了多维度的讨论。这种坦诚报告负结果的做法提升了结论的可信度。
- **对表示空间理论的实证支撑**：通过重建实验将"指纹损失了多少分子结构信息"这一抽象问题转化为"能否从指纹恢复 SMILES"的具体可量化指标，是评估表示信息密度的少见且直观视角。

## 8. 潜在问题与局限性

- **集成胜出而非单一架构胜出**：头名结果来自 7 个模型的集成（3 骨架×2 token 表示+AE），而消融中"Best Transformer-only 在 22 项中赢过全部 12×2 指纹基线中的多少项"没有在 TDC 上逐项报告；混合架构的重要性与单个组件的贡献之间存在灰色地带。
- **与 SOTA Transformer 的可比性限制**：论文与 MapLight+GNN、MiniMol、MoLFormer 等预训练大模型的比较借用 TDC leaderboard 上各自报告的数字。这类跨论文比较未统一训练/验证划分后的早期停止、未统一超参数搜索预算，且 MiniMol 是 2024 年之后的方法；与最新预训练模型（如 QM 感知分子 LM）间的差距可能随模型规模扩大而变化。
- **ADMET 分类任务的短板解释不足**：全 22 个基准中，回归平均排名第 1（3.9），但分类平均排名明显弱于 MapLight+GNN 等。论文仅以"数据规模不足""子结构-位置多样性不够"定性归因，未给出分类失败任务的模式化诊断（例如是否集中在不平衡二分类、CYP 多任务、HIA 的非常规组织来源）。
- **"无外部预训练"约束的双刃剑**：整套方法刻意回避预训练权重，因此不享受跨数据集的迁移先验；在 ADMET 数据量极小（如数千条）的 benchmark 上，这种"自给自足"是否真正稳健，仍需观察；部分任务与预训练模型的差异可能正源于此。
- **近无损可逆性理想化**：重建实验以分布内单个子结构可拼装为前提。真实场景中环融合的复杂环境、超过 2 跳半径的非局部相互作用、以及镜像/轴向手性均可能超出编码范围——作者将全部失败归于立体化学差异，但这个结论只是在 HIV→Lipophilicity 一个跨界数据对上验证的，通用性有限。
- **每次分子 token 数超 300 的截断处理**：未给出截断后遇到丢失子结构时的分类边界效应；如果长链大分子（如多肽、核酸类似物）中有重要药效团落在截断窗口外，表现可能打折。
- **图距离 vs 3D 距离的适用范围边界**：作者用"最短路径距离"替代几何距离，对柔性大分子只编码拓扑；若目标性质高度依赖构象（如蛋白-配体结合、溶剂化构象统计），SuRGE 无法覆盖。
- **没有显式的"失败任务清单"**：虽然报告了每任务的 rank，但缺少对"哪个基准上比 XGB 还差"的细致复盘；某些 ADMET endpoint 很可能被连续指纹的 89% 稀疏 + 300 token 截断 + 3 层 Transformer 的组合所限制，而论文未深入这一层诊断。

## 9. 总结性评价

这是一篇在"轻量级与预训练范式"之间寻找第三种路径的、实验密度相当扎实的方法学论文。它将三个本不相关的成熟概念——ECFP 的圆形子结构枚举、随机哈希散射的连续向量、RoPE 的旋转编码——有机结合为一个无需预训练、可重建、为图距离定制的分子编码方案，且整个技术栈只需不到数小时的单卡训练量即可达到 TDC ADMET 回归组第一名，这对分子 ML 社区具有较高的实用参考价值。论文的贡献不在单个组件的新颖性（Morgan、哈希散列、RoPE 都是既有工具），而在于它们的组合方式与系统性评估：既有 22 基准的集成成绩，也有 WEECFP-S vs WEECFP-Scatter、SuRGE md vs ref3、CNN/Transformer/MLP 等多维消融，还有从 1024 维向量恢复 SMILES 的逆向验证，从而使"连续、轻量、无预训练也能逼近 SOTA"这一论断获得多角度支撑。局限则集中在跨论文对比公平性、分类任务的短板解释、以及对"预训练必要性"挑战的边界（要做的只是 ADMET 规模的中小分子性质预测；一旦外推到需要长期依赖与大规模语义先验的生成型任务，该路线并不适用）。总体而言，它像一个"简约但充满聪明的确定性先验"的匠心之作——在一个以预训练模型为风向标的时期，重新拾起经典指纹的归纳偏置并注入现代的旋转位置编码思想，为分子表示学习提供了一个低成本、高可解释性、可审计的强力基线，值得被社区作为未来 ADMET 系综方法的默认对照之一。
