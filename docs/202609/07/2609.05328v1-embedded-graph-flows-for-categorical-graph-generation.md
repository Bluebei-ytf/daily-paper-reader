## 摘要
生成类别图需要选择节点和边的类型，以形成不依赖于节点顺序的连贯结构。许多图生成器将类别编码为固定独热向量，这可能施加一种人为的几何结构，使类别之间等距。我们提出了嵌入图流（EGF），一种生成模型，为节点和无序边类别学习连续嵌入，并使用置换等变的图变换器将高斯噪声传输到这些学习到的端点。最终的读出模块将嵌入映射回离散的图类别。在分子基准测试中，EGF取得了有竞争力的表现。在QM9上，EGF在三种方法中所有四个报告的指标上均取得了最佳结果，包括Fréchet ChemNet距离（FCD）为0.150，而基于类别扩散的基线DiGress为0.717，基于桥接的基线GruM为0.812。当应用于ZINC250k中的较大分子时，EGF在使用邻域子图成对距离核（NSPDK）时保持了最低的最大均值差异（MMD），表明与参考分子的局部子结构高度一致。我们的代码可在 https://github.com/Trusted-System-Lab/EGF 获取。

## Abstract
Generating categorical graphs requires choosing node and edge types that form a coherent structure without depending on node order. Many graph generators encode categories as fixed one-hot vectors, which can impose an artificial geometry in which categories are equidistant. We propose Embedded Graph Flows (EGF), a generative model that learns continuous embeddings for node and unordered-edge categories and transports Gaussian noise towards these learnt endpoints using a permutation-equivariant graph transformer. A terminal readout maps the embeddings back to discrete graph categories. Across molecular benchmarks, EGF achieved competitive performance. On QM9, EGF gives the best result on all four reported metrics among the three methods, including a Fréchet ChemNet Distance (FCD) of 0.150, compared with 0.717 for the categorical-diffusion baseline DiGress and 0.812 for the bridge-based baseline GruM. When applied to larger molecules in ZINC250k, EGF retains the lowest maximum mean discrepancy (MMD) using the neighbourhood subgraph pairwise distance kernel (NSPDK), indicating close agreement with the local substructures of the reference molecules. Our code is available at https://github.com/Trusted-System-Lab/EGF.

# 面向类别图生成的嵌入图流（EGF）论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：生成分类图（categorical graph）要求模型同时确定节点与边的类型，以形成连贯的分子结构，且图分布必须对节点重标号（permutation）保持不变。这类需求在分子生成中极为关键——任何不兼容的原子-化学键组合都会导致无效结构。
- **核心问题**：现有图生成方法通常将类别编码为固定的 one-hot 向量或概率顶点，使得所有类别在嵌入空间中被强制设为“等距”（equidistant）关系，这是一种人为的、固定的几何结构，无法反映类别之间的真实语义关系。作者提出疑问：能否为类别化图**学习**端点的几何结构，同时处理 padding、保持无向边对称性和节点重标号等变性？
- **整体含义**：论文提出 Embedded Graph Flows（EGF）——一种将类别图生成问题建模为“连续嵌入空间中的流传输”的新方法，并在分子图基准测试（QM9、ZINC250k）上验证了其有效性。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将图类别生成分解为**两阶段**表示：
  1. **学习嵌入阶段**：节点类别与无序边类别分别通过可训练的嵌入矩阵（$W_A$、$W_B$）映射到连续空间 $\mathbb{R}^d$ 中的“锚点”（anchors），作为干净端点。
  2. **流传输阶段**：从高斯噪声出发，以直线条件路径（rectified flow）向干净端点的方向传输，用一个置换等变的图 Transformer 预测干净嵌入并定义向量场。
- 与传统方法的本质区别：**端点的几何关系不是人为固定的，而是由数据学习得到**。

### 2.2 状态表示
- 图状态存储为节点数组和对称边数组，每个无向对 $(i,j)$ 只存一个共享向量，镜像到 $(j,i)$。
- mask 区分有效节点与 padding；训练和生成只作用于激活坐标集合 $\mathcal{A}(m)$（激活节点 + 激活无序对）。
- 额外引入“对角状态”$D_i$（位于边数组对角线上）作为网络的辅助输入通道，但不参与最终的类别监督。

### 2.3 条件路径与目标
- 各激活坐标独立采样高斯噪声：$Z_0 \sim \mathcal{N}(0, I_d)$。
- 条件路径为直线插值：$Z_t = (1-t)Z_0 + tZ_1$，$t \sim \mathcal{U}(0,1)$。
- 条件速度场为 $v = x - z_0$，其中 $x$ 为干净嵌入。网络通过预测干净嵌入 $\hat{x}_\theta$，由 $\hat{v} = (\hat{x}_\theta - z_t)/(1-t)$ 等价地得到速度。在平方误差损失下，最优预测即条件后验均值，从而恢复边际向量场。

### 2.4 双分支训练目标
EGF 用**两个分支**共享一个图 Transformer：
- **去噪分支（概率 $1-p$）**：沿 Gaussian 路径预测干净嵌入，采用 type-wise 归一化的 MSE 损失 $L_{\mathrm{den}}$，节点和边的损失分量按各自类别坐标数量分别归一化，避免平方级增长的边数扭曲两类贡献。
- **解码分支（概率 $p$）**：在 $t=1$ 处，将干净嵌入与高斯噪声混合后送入同一网络，输出经非共享的线性映射得到类别 logits，用交叉熵损失 $L_{\mathrm{dec}}$ 学习终端分类读出。
- 总损失：$L = (1-p)\,L_{\mathrm{den}} + p\,L_{\mathrm{dec}}$。
- 该设计参考了 Embedded Language Flows（ELF）的思路，但为适配图结构做了一系列修改（mask、无向边共享状态、置换等变）。

### 2.5 网络架构
- 采用置换等变图 Transformer，节点特征与边特征协同更新。
- 每一层中，多头注意力计算节点间分数，其中加入由当前边特征导出的可学习标量项 $\gamma_{ij}$；对查询和键向量使用独立的层归一化，并可选用带上限的正切压缩来调整注意力得分。
- 边信息为对称结构，网络显式平均两个镜像方向以严格保持无向性。
- 网络接收时间嵌入与模式指示符（denoise/decode）作为条件。

### 2.6 采样
- 从经验图尺寸分布中采样 $K$，构造 mask。
- 从标准高斯初始状态出发，使用 $S$ 步显式 Euler 积分更新节点/边状态和“对角状态”，每一步根据预测的干净嵌入更新（公式10、11）。最后一个积分步将状态直接置于最后一步预测的干净嵌入上（设定 $t_S=1$ 使得 $z_S = \hat{x}_{S-1}$）。
- 最后，将“对角状态”切换为解码训练的固定值，再做一次解码模式前馈，用 argmax 选择每个激活坐标的类别。
- 输出类别后，经过领域适配器完成分子重建与有效性检验。

## 6. 论文的主要结论与发现

1. **类别嵌入的几何可以是学出来的**：EGF 通过可学习的连续锚点取代 one-hot 等距几何，在实验中表明这种灵活的表示能够提高生成质量，至少在小分子、中等规模数据集上是如此。
2. **在小分子上表现全面领先**：QM9 上所有指标（有效性、FCD、NSPDK-MMD、骨架相似度）均超越 DiGress 和 GruM，特别是 FCD 为 0.150，远低于两个基线。
3. **在大分子上各有长短**：ZINC250k 上，EGF 抓住了图局部/结构相似性（NSPDK-MMD 最优），但广泛分布匹配（FCD）有效性和骨架多样性不如 GruM，说明优良的局部子结构统计并不自动带来较高的整体化学有效性。
4. **指标之间具有互补性**：FCD 衡量全局特征分布，MMD-NSPDK 衡局部图结构的分布，骨架相似度则面向药物化学中的骨架多样性，EGF 在不同指标上的表现并不完全一致。

## 7. 优点

- **方法创新性强**：将类别嵌入视作可学习的端点几何，是对此前 one-hot 固定几何（DiGress/GruM）或 simplex 内部传输（CatFlow）视角的一个重要改进方向。
- **理论正确性**：以流匹配（flow matching）为框架，从平方误差至后验均值的推导展示了去噪目标与边际向量场的一致性。
- **对称性设计完整**：置换等变与无向边镜像对称同时得到保证；mask 和 padding 的处理清晰，符号表述一致。
- **双分支共享参数设计具有实用价值**：去噪与终端读出一体化共享网络表示，与实际采样的需求（需要去噪更新和终端 decode）自然衔接。
- **评测透明**：用统一评估器重算所有方法的指标，公开源码（在非商业许可下），便于复现验证。

## 8. 不足与局限

- **缺少消融实验**：论文没有量化各组件（学习端点几何、双分支训练方式、无向边共享、掩码策略等）对最终性能的贡献；尤其“可学习嵌入优于 one-hot 的增益到底有多大”并未直接验证。
- **单一训练种子与较少重复**：在小数据集 QM9 上部分指标差异可能处于同一噪声水平；ZINC250k 上 NSPDK-MMD 的差距很小（0.0028 vs. 0.0024 vs. 0.0032），无置信区间。
- **大分子生成表现仍有差距**：ZINC250k 上有效性低于 GruM，FCD 也比 GruM 高约 46%，说明针对大规模图的生成在化学约束满足与全局分布匹配上仍有较大上升空间。
- **类别级共享表现力有限**：嵌入仅由类别线性映射生成，不能感知局部环境；对更大分子中多样的化学环境，单一锚点表达不足以建模细微变化（作者在未来工作中提议引入预训练分子编码器）。

- **应用领域受限**：编码中未包含立体化学、同位素信息、自由基电子等信息，限制了在更细粒度药物分子发现上的可用范围。
- **伦理与知识产权考虑**：论文在结尾提及模型授权和模型使用控制等安全话题，但这部分属于展望性说明，尚未实验验证。
