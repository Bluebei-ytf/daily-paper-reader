## 摘要
SALTED提供了一个开源Python包，用于基于输入原子坐标和物种，对分子和凝聚相体系中的量子力学电子密度n(r)进行机器学习。该程序采用电子密度的线性原子中心分解，这使得它在不同原子构型中具有高度可转移性，只要它们共享相似的化学环境。由于这种表示选择，SALTED自然地与基于原子轨道的最先进电子结构程序（即CP2K、FHI-aims和PySCF）接口，并可从这些程序生成参考电子密度数据用于训练模型。学习算法基于高斯过程回归的对称自适应扩展，使SALTED在小数据情况下特别高效。得益于矢量场核函数的实现，SALTED还可以学习电子密度对外加电场的一阶响应∂n(r)/∂E。SALTED在计算工作流中的应用已在多种情境中显示出其效用，包括极化矢量和极化率张量的计算、QM/MM分子动力学模拟中库仑力的精确评估，以及大规模二维材料的电子结构研究。

## Abstract
SALTED provides an open-source Python package for machine learning the quantum-mechanical electron density, $n(\mathbf{r})$, in molecular and condensed-phase systems based on input atomic coordinates and species. The program adopts a linear atom-centered decomposition of the electron density, which makes it highly transferable across diverse atomistic configurations sharing similar chemical environments. Because of this representation choice, SALTED is naturally interfaced with state-of-the-art electronic-structure programs based on atomic orbitals, namely CP2K, FHI-aims, and PySCF, from which reference electron-density data can be generated and used to train a model. The learning algorithm is based on a symmetry-adapted extension of Gaussian process regression, making SALTED especially efficient in small-data regimes. Thanks to the implementation of vector-field kernel functions, SALTED can also learn the first-order response of the electron density to applied electric fields, $\partial n(\mathbf{r})/\partial \mathbf{E}$. The application of SALTED within computational workflows has already shown its utility in a wide variety of contexts, including the calculation of polarization vectors and polarizability tensors, the accurate evaluation of Coulomb forces in QM/MM molecular-dynamics simulations, and electronic-structure studies of large-scale 2D materials.

## 1. 核心问题与研究动机

- **背景**：密度泛函理论（DFT）是材料与分子模拟中最成功的电子结构方法之一，但其计算成本在面向大体系、长时程、高通量筛选时仍然过高。数据驱动的机器学习方法若能直接预测 DFT 最核心的物理量——实空间电子密度 n(r)，则有望以极低成本获得多种衍生性质（能量、力、静电性质、极化率、甚至单次对角化后的 Kohn–Sham 性质），从而替代大量昂贵 DFT 计算。
- **核心问题**：如何在保证可迁移性（transferability）的前提下，用尽可能少的参考数据，以机器学习方式构建高精度电子密度（及密度对外场响应）的预测模型，并给出一个实用的、可嵌入现有电子结构工作流的开源工具。
- **整体含义**：SALTED（Symmetry-Adapted Learning of Tensorial Electron Densities）正是为这一需求提供的开源 Python 程序，采用了**原子中心线性分解 + 对称自适应高斯过程回归（SA-GPR）**的组合，以小数据即可训练出可靠模型，并通过与主流原子轨道类电子结构程序（CP2K、FHI-aims、PySCF）的天然接口嵌入计算工作流。

## 2. 方法论

### 2.1 核心思想：原子中心的 RI 线性展开
电子密度不直接在实空间 3D 网格上回归，而是投影到以每个原子为中心的线性基组上：

\[
n(\mathbf{r}) = \sum_{in\lambda\mu} c^i_{n\lambda\mu} \sum_{\mathbf{u}} R_{\lambda n}(|\mathbf{r}-\mathbf{r}_i-\mathbf{u}|) Y_{\lambda\mu}(\widehat{\mathbf{r}-\mathbf{r}_i-\mathbf{u}})
\]

- 下标 i 为原子；u 为周期体系的晶格平移矢量；R_{\lambda n} 为径向函数；Y_{\lambda\mu} 为球谐函数；c^i_{n\lambda\mu} 为待学习的密度展开系数。
- 参考系数可以从电子结构代码中的 resolution-of-the-identity（RI）直接获得——这一选择天然兼容基于原子轨道的 DFT 与波函数程序，是该表示能够实用的关键工程保证。

### 2.2 学习算法
- **对称自适应高斯过程回归（SA-GPR）**：使用球张量型核函数 K_\lambda 从原子密度特征构建，严格满足 O(3) 对称性；特征通过 `featomic` 库（metatensor 生态）计算。
- **小数据数据高效性**：由于 GPR 约束的函数空间较小，能有效避免过拟合，在训练集仅 10²–10³ 个高精度电子结构计算量级时即可获得可用模型——这一点对该方法用于高等级电子结构方法（如杂化泛函或后 HF）尤其重要。
- **电场响应的学习**：通过对各 \lambda 通道核函数做特定线性组合，实现“矢量场核函数”，模型可学习电子密度对外加均匀电场的一阶响应 ∂n/∂E——这种响应量本质上属于 3D 矢量场，需要满足相应对称变换；同时这也使极化矢量、极化率的计算成为直接任务。
- **长程特征（LODE）**：通过 `featomic` 可引入长距离等变描述符（LODE，Long-Distance Equivariants），用于捕捉高度极化体系（如金属框架、电解液界面）中非局域的电子密度重新分布。

### 2.3 软件与工作流
- 三阶段工作流：**数据准备（reference density 与 RI 系数生成）→ 模型训练 → 模型预测**；全部由单一 `inp.yaml` 配置管理。
- 操作是命令行分区段方式而非单次调用 API；**每个步骤可独立执行、断点重启、跨 HPC 节点重分配**，适合大规模模型训练。
- **接口**：CP2K（提供网格数据 .cube 和专门 `density_fitting` 模块）、FHI-aims（直接输出 RI 系数）、PySCF（直接引用 RI 系数）；三种数据格式在 SALTED 中统一到一个共享格式。
- **性能工程**：关键步骤（描述符收缩、核矩阵组装）由 Numba 编译内核加速；并行化通过 mpi4py 实现，支持单机多核到多节点集群；提供 Dockerfile 供可移植性需求。
- 注意：SALTED 在元数据层面所表示的预测系数是建立在原子轨道径向函数 + 球谐函数的线性基组上的标量/矢量场回归，不同于 DeepDFT 等直接在 3D 网格或其它全连接神经网络的范式（后者在"状态"一节有系统列举）。

## 6. 主要结论与发现

- SALTED 是一个实用性强、可迁移性好的开源工具，提供了一种基于对称自适应 GPR + 原子线性基组来预测电子密度及其一阶电场响应的现成实现。
- 它在"数据高效性 + 小数据域"有天然优势；能自然生成 RI 系数；并且能与不同主流电子结构程序无缝集成。
- 从已有研究应用论断数据表明：SALTED 可在特定任务中提供约 3–4 个数量级的降速，并在大尺度二维材料体系（如 Moiré 超胞）中解锁原本不可能的标准 DFT 模拟。
- 作者特别强调：可在预测密度基础上直接利用 RI 系数做晶体结构精修（X-ray/电子衍射）；这形成了一条有希望的低成本精度拓展路径。

## 7. 优点与亮点

- **表示选择合理**：原子中心线性分解天然适配于基于原子轨道的电子结构代码，用少量浮点参数即表达密度；避免在 3D 实空间格点采样，减少了冗余数据和计算负担。
- **严格对称性保证**：核函数满足 O(3) 精确对称性，能天然处理分子/晶体体系的旋转、平移对称性，避免训练数据对对称性的浪费。
- **GPR 小数据高效**：在训练数据极少的场景下（约 10² 个高精度电子结构算例），模型仍然可靠——此种数据量在比 DFT 更高级别的量化方法中非常现实。
- **物理透明的可解释性**：原子中心基组系数是可物理分析的（多极分解角度）；密度又是可给下游直接使用的可迁移量。
- **矢量场扩展能力**：实现可学习 ∂n/∂E，即电子密度对外加电场的线性响应的模型；这使 SALTED 区别于只学静态 n(r) 的常见模型。
- **接口与工程**：覆盖 CP2K、FHI-aims 与 PySCF 三种流行接口；能将多种电子结构代码产生的密度统一到同一种张量格式；工作流支持 checkpoint/断点续算，适配 HPC。
- **生态兼容**：借助 metatensor/featomic 生态，可方便地接入 LODE 长程特征，能捕获传统短程 ML 无法捕捉的长程静电重分布。

## 8. 不足与局限

- **缺少公开基准与精确实验报告**：作为软件论文，读者无法从本文直接看到 SALTED 与其他方法在同一任务上的量化精度对比（例如训练集规模-误差曲线、能量/力/极化率误差表），不易判断不同任务中的实际精度水平。
