## 摘要
分子性质预测需要能够从有限标注数据泛化到结构新颖化合物的表示。现有分子预训练方法通常依赖单一视图：基于图的方法建模原子-键拓扑，但提供的片段级监督有限；而指纹描述符编码化学模式，但通常被用作固定的辅助特征。我们提出 HiFi-Mol，一个多视图框架，在下游集成之前分别预训练一个分层图编码器和一个上下文化指纹编码器。图分支使用片段感知掩码与多分辨率监督来捕获子结构感知表示，而指纹分支对来自七个指纹家族的活跃条目进行标记化，并应用掩码语言建模来学习上下文化嵌入。在微调过程中，HiFi-Mol 将投影后的多分辨率图特征与指纹嵌入相结合，用于下游预测。在 scaffold split 下的 MoleculeNet 基准上评估，HiFi-Mol 在八个分类任务上相较最佳基线实现了平均 ROC-AUC 2.77% 的提升，同时在三个回归任务上保持有竞争力的性能。进一步分析表明，片段感知掩码提高了图表示质量，分类结果展示了单个图与指纹变体在不同数据集上的优势，证实了这两种视图提供了互补的预测信号。

## Abstract
Molecular property prediction requires representations that generalize from limited labeled data to structurally novel compounds. Existing molecular pretraining methods often rely on a single view: graph-based approaches model atom-bond topology but provide limited fragment-level supervision, whereas fingerprint descriptors encode chemical patterns but are typically used as fixed auxiliary features. We propose HiFi-Mol, a multi-view framework that separately pretrains a hierarchical graph encoder and a contextualized fingerprint encoder before downstream integration. The graph branch uses fragment-aware masking with multi-resolution supervision to capture substructure-aware representations, while the fingerprint branch tokenizes active entries from seven fingerprint families and applies masked language modeling to learn contextualized embeddings. During fine-tuning, HiFi-Mol combines projected multi-resolution graph features with fingerprint embeddings for downstream prediction. Evaluated on MoleculeNet benchmarks under the scaffold split, HiFi-Mol achieves a 2.77% improvement in average ROC-AUC over the best baseline across eight classification tasks while maintaining competitive performance on three regression tasks. Further analyses reveal that fragment-aware masking improves graph representation quality, and classification results demonstrate dataset-dependent strengths of the individual graph and fingerprint variants, confirming that the two views provide complementary predictive signals.

  - **指纹方法**：编码圆形子结构、药效团、拓扑关系等化学模式，与图表示互补，但通常仅作为静态辅助向量被浅层拼接，无法建模描述符间的上下文依赖关系。
- **整体含义**：论文将图拓扑与指纹描述符视为具有不同归纳偏置的互补分子视图，提出 HiFi-Mol，在预训练阶段分别学习两个视图，在下游阶段融合，以提升有限标注下对新结构分子的泛化能力。

## 2. 方法论

### 2.1 核心思想

- 多视图分子预训练框架，包含**分层图编码器（Φ_GNN）**与**上下文化指纹编码器（Φ_FP）**；
- **不在预训练阶段强制共享空间**，而是以视图特定的目标分别预训练，仅在微调阶段进行融合；
- 图分支通过片段感知掩码（FAM）+ 多分辨率监督学习子结构感知表示；指纹分支通过联合 SMILES–指纹 token 序列的掩码语言建模学习上下文化描述符表示。

### 2.2 关键技术细节

**(1) 分层图构建**
- 两阶段分解：先用 BRICS 切断逆合成有意义的键得到初始片段，再用 SSSR 环细化将含环粗片段拆分为最小化学一致环状子结构；
- 每个片段规范化为 SMILES 并通过字典函数 φ 映射为唯一 ID，出现次数 < τ_min = 10 的片段归入 ⟨UNK⟩；
- 层次图 G = (V, E)，V = V_atom ∪ V_frag ∪ {v_global}，E = E_bond ∪ E_hier。

**(2) 片段感知掩码（FAM）**
- 以比例 r_f = 0.15 采样片段节点作为掩码单元，并将掩码传播至其组成原子与关联键；
- 若诱导的原子掩码比例低于 r_a = 0.25，则额外均匀采样原子补足；
- 掩码键定义为至少有一个端点被掩码的化学键。

**(3) 分层图编码**
- 使用共享 GINE 骨干，节点特征来自原子属性、片段字典 ID 或全局上下文，掩码节点替换为可学习掩码嵌入；
- 边特征融合键属性与层次关系类型（原子-片段、片段-原子、片段-片段、片段-全局、全局-片段）；
- 逐层更新公式（式 8）：`h_i^(l) = MLP^(l)((1+ε^(l))h_i^(l-1) + Σ_{j∈N(i)} ReLU(h_j^(l-1)+e_ij))`。

**(4) 多分辨率预训练目标（5 个）**
- **全局对比损失 L_CL**：对同一分子生成两个独立 FAM 掩码视图，对全局节点嵌入做 ℓ2 归一化后用 InfoNCE（τ = 0.1）优化；
- **片段身份预测 L_frag**：对掩码片段节点用线性分类头预测其字典 ID；
- **原子类型预测 L_atom**：对掩码原子节点预测原子类型；
- **键类型预测 L_bond**：用两层 MLP 对端点表示拼接预测键类型；
- **距离预测 L_dist**：距离解码器 f_dist 从最终表示预测采样原子对（含成键与随机非成键对）的欧氏距离，3D 坐标仅预训练时可用。

**(5) 不确定性损失加权**
- 采用 Kendall 等的不确定性加权，为每个目标引入可学习方差 σ²_t：`L_G = Σ_t (1/(2σ²_t) L_t + log σ_t)`，第一项自适应降低高不确定性目标权重，log 项防止 σ_t 平凡增长。

**(6) 上下文化指纹预训练**
- 从 7 个指纹家族构建指纹视图：ECFP4、ECFP6（局部圆形环境）、FCFP4、FCFP6（药效团特征）、ATOMPAIR（长程拓扑）、TOPTOR（扭转片段）、MACCS（可解释结构键）；
- 每个活跃条目构造离散 token `<fp_name_index_value>`，得到稀疏指纹 token 序列 X_FP；与 SMILES token 序列拼接为联合序列 X_SF = [X_SMI ‖ X_FP]；
- Φ_FP 由 ChemFLM（基于 ModernBERT 的指纹语言模型）初始化；
- 输入表示为 token 嵌入与段嵌入之和（式 15），经 L_FP 层自注意力处理；
- 预训练时随机将 15% 联合 token 替换为 mask，用 MLM 头重建原始 token，损失 L_FP 为掩码位置上的负对数似然。

**(7) 多视图下游融合**
- 图视图分子级表示：原子级 H_atom 均值池化得 h_atom，片段级 H_frag 最大值池化得 h_frag，全局节点 h_global 直接保留；
- 指纹视图：对 H_SF 均值池化得 h_FP；
- 各视图经两层 MLP 投影头（含 BN、SiLU、dropout）映射到 128 维，拼接后送入任务特定预测头：`ẑ_g = f_GNN([h_atom‖h_frag‖h_global])`，`z_fp = f_FP(h_FP)`，`ŷ = f_pred([z_g‖z_fp])`。
