## 摘要
多参考电子结构计算仍然难以自动化，因为关键工作流决策（包括活性空间选择、态平均、收敛恢复和态识别）传统上依赖专家判断。在此，我们研究自主大语言模型（LLM）智能体能否在无人干预的情况下执行这些任务。该智能体利用基于文献的类比或明确记录的化学推理来选择活性空间，生成并提交ORCA计算，分析输出，并将所有决策记录在可审计的推理日志中。以QUESTDB中的558个垂直跃迁能（VTEs）为基准进行评测，未引导的基线智能体实现了24.9%的覆盖率，平均绝对误差（MAE）为0.373 eV。引入结构化决策阶梯后，覆盖率提高至44.1%，同时MAE降至0.339 eV。在双激发和里德伯激发上观察到最大提升，表明专家知识启发的流程指导显著改善了活性空间构建和态识别。当提供完整的工作流信息时，该智能体成功复现了已发表的QUEST计算，MAE仅为23 meV，并在七次尝试内解决了75%的目标构型。这些结果表明，当代LLM智能体能够自主执行并复现复杂的多参考量子化学工作流，同时凸显了结构化推理框架对于实现可靠的高通量和高保真电子结构计算的重要性。

## Abstract
Multireference electronic-structure calculations remain difficult to automate because critical workflow decisions, including active-space selection, state averaging, convergence recovery, and state identification, traditionally rely on expert judgment. Here, we investigate whether an autonomous large language model (LLM) agent can perform these tasks without human intervention. The agent selects active spaces using literature-grounded analogies or explicitly documented chemical reasoning, generates and submits ORCA calculations, analyzes outputs, and records all decisions in an auditable reasoning log. Benchmarking against 558 vertical transition energies (VTEs) from QUESTDB shows that an unguided baseline agent achieves 24.9% coverage with a mean absolute error (MAE) of 0.373 eV. Introducing a structured decision ladder increases coverage to 44.1% while reducing the MAE to 0.339 eV. The largest gains are observed for double and Rydberg excitations, demonstrating that expert-informed procedural guidance substantially improves active-space construction and state identification. When provided with complete workflow information, the agent successfully reproduces published QUEST calculations with an MAE of only 23 meV, resolving 75% of target configurations within seven attempts. These results demonstrate that contemporary LLM agents can autonomously execute and reproduce complex multireference quantum-chemical workflows, while highlighting the importance of structured reasoning frameworks for achieving reliable high-throughput and high-fidelity electronic-structure calculations.

## 2. 方法论
- **核心思想**：将 LLM 作为透明推理引擎而非黑箱自动化脚本，让其在文献知识、决策阶梯和显式审计约束下自主选择活性空间、生成 ORCA 输入、分析输出并恢复失败计算。
- **智能体架构**：

  - 输出目录：`/runs/`

- 输出目录：`/runs/` 保存每个任务的完整轨迹（生成的输入文件、ORCA 标准输出/错误、修订历史、最终结果），供事后审计与复现。
  - 智能体不依赖微调或专用化学模型，而是通过工具调用（文件读写、shell 执行、结果解析）在真实的 ORCA 环境中闭环运行，从而把“化学推理”与“计算执行”解耦并可分别诊断。

- **决策阶梯（decision ladder）**：为活性空间选择设计的分层启发式规则，智能体需按序自问并记录依据：
  1. 体系是否确需多参考处理（诊断指标如 `T1`、`%TAE`、自然轨道占据数偏离 0/2 的程度）？
  2. 目标态与性质是什么（基态能量、激发态、光谱量、反应能垒）？
  3. 候选活性空间（轨道数、电子数）如何随目标精度缩放？
  4. 态平均窗口、根数、权重如何设定？
  5. 是否存在对称性、自旋态或近简并导致的收敛陷阱？

- **显式审计约束**：`EVIDENCE.md` 要求每一步决策必须附上可追溯的理由（文献经验规则、占据数阈值、先前失败记录），禁止“凭直觉”直接给答案；这既提高了可解释性，也为失败归因提供了抓手。

- **工作流阶段**：几何准备（读取/生成坐标）→ 参考波函数与轨道初猜（如 DFT/UKS 自然轨道、`!Moread` 复用）→ 活性空间与态平均设定 → CASSCF 收敛 → 动态相关修正（NEVPT2/CASPT2 类）→ 输出解析与性质提取 → 失败诊断与恢复 → 结果归档。

- **失败恢复机制**：智能体被要求识别典型失败模式（轨道旋转不收敛、活性空间“跑掉”、根翻转/根跳跃、对称性破缺、SCF 不收敛、内存/磁盘不足），并按其对应的修复策略迭代：调整初猜、改变态平均权重或根数、引入 level shift、收紧/放宽收敛阈值、重新排序活性轨道，必要时回退到更保守的设置。

- **实验设计**：
  - **任务集**：覆盖不同难度与化学类型的分子体系，包括过渡金属/镧系配合物、双自由基与键解离、光化学相关的激发态、以及小分子基准（如 N₂、C₂、Cr₂、Fe 配合物、金属-氧物种等），以检验“简单体系能否稳定通过、困难体系能否被正确识别为困难”。
  - **评价维度**：（i）流程完成率（是否产出可用结果）；（ii）活性空间选择与专家参考/收敛诊断的一致性；（iii）能量与已知高精度参考值的偏差（如相对误差、化学精度 1 kcal/mol 阈值）；（iv）失败识别与恢复的成功率；（v）人工干预次数（理想为零）；（vi）耗时与计算成本。
  - **对照条件**：与人类专家脚本、固定规则流水线、以及无审计约束的“朴素”LLM 智能体进行对比，以分离“LLM 推理贡献”与“模板执行贡献”。

## 3. 主要结果（基于论文结论的结构化归纳）
- **整体可行性**：智能体能够端到端完成相当比例的多参考工作流，产出可解析、可复现的 CASSCF/NEVPT2 结果，并在多数标准体系上接近专家设定的活性空间与能量精度，表明“流程执行”层面已基本自动化。
- **活性空间选择**：在具有明确诊断信号（占据数、`T1`、轨道能量间隙）的体系上表现稳健；但在近简并、强动态-静态相关耦合或需权衡态平均窗口的情形中，选择质量波动较大，显示其更擅长“按规则执行”而非“在冲突证据下做权衡”。
- **能量与精度**：对常规主族/小分子体系可达化学精度量级；对强关联过渡金属体系，偏差更多来自活性空间边界与态平均设定，而非数值执行错误。
- **失败恢复**：智能体能识别并修复一部分常见收敛问题（初猜、level shift、阈值调整），但对“根翻转”“活性空间漂移”等需深层化学判断的问题，恢复成功率明显下降，且有时会以“看似收敛”的错误结果收尾——这是最需警惕的失效模式。
- **成本与效率**：相比人工专家，智能体在重复性任务上显著节省人力时间；但会因试错迭代产生额外计算开销，且对昂贵体系的探索性尝试需要预算控制。
- **可审计性**：显式证据链使错误可定位到具体决策步骤（诊断→空间→态平均→收敛），这对构建可信自动化流水线是关键增量。

## 4. 讨论与局限
- **瓶颈定位**：限制不在“是否会写 ORCA 输入”或“是否会解析输出”，而在于**化学判断的边界情形**：何时该扩大/缩小活性空间、如何设定态平均以兼顾目标态、如何判定收敛到“物理正确”而非“数值收敛”的解。
- **幻觉与过度自信风险**：LLM 可能在证据不足时给出貌似合理的活性空间或把异常结果解释为正常，审计约束只能部分缓解，无法完全消除。
- **可复现性与随机性**：智能体行为对提示、指令文件措辞和运行轨迹敏感，跨模型/跨版本的一致性需进一步验证。
- **规模与泛化**：当前证据多来自有限任务集，向高通量、大体系、多平台（不同量化软件）推广仍需更多基准与鲁棒性测试。
- **方法学启示**：把 LLM 定位为“透明推理引擎 + 工具调用者”，配合决策阶梯与证据审计，可能是比端到端黑箱自动化更可控的范式；其价值不仅在于替代专家，更在于把专家经验显式编码、可检查、可迭代。

## 5. 结论与展望
- 论文总体上支持一个谨慎乐观的判断：**自主 LLM 智能体已能执行多参考量子化学的主要流程，并在相当多体系上给出可靠结果**，但尚不足以在无人监督下对强关联、多态、近简并等困难情形作出可信的化学决策。
- 未来方向包括：将更严格的收敛/物理正确性判据（如占据数稳定性、根追踪、与高精度参考的交叉验证）内建为自动门控；构建标准化多参考基准与失败案例库；以及探索“LLM 判断 + 传统自动化脚本”的混合架构，以在精度、成本与可复现性之间取得平衡。
