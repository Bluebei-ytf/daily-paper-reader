## 摘要
科学智能体可以利用积累的证据来修正其问题和实验策略，从而超越自动化模型构建。挑战在于如何在异构任务中维持这种自适应能力，同时避免将决策过拟合到内部验证。吸收、分布、代谢、排泄和毒性（ADMET）预测在多样的实验、数据集和化学领域中提供了一个高要求的场景。因此，我们开发了ADMET-EvO，一种证据门控智能体，它形式化终点、生成可证伪的假设，并在数据、特征和模型维度上测试干预措施。它将得到支持的、被拒绝的和不确定的结果向前传递，以指导每一个新周期。在包含22项任务的Therapeutics Data Commons（TDC）ADMET基准测试中，ADMET-EvO取得了最高的任务归一化分数96.77。在预定义的非劣效性界限内，证据引导的选择将累计拟合时间减少了72.2%。它还形式化了43项与毒性相关的任务，并构建了终点特异性预测器。这些结果共同表明，ADMET-EvO能够随时间积累证据、修正策略并扩展其研究范围。

## Abstract
Scientific agents can move beyond automated model building by using accumulated evidence to revise both their questions and experimental strategies. The challenge is sustaining this adaptation across heterogeneous tasks without overfitting decisions to internal validation. Absorption, distribution, metabolism, excretion and toxicity (ADMET) prediction provides a demanding setting across diverse assays, datasets and chemical domains. We therefore developed ADMET-EvO, an evidence-gated agent that formalizes endpoints, generates falsifiable hypotheses and tests interventions across data, feature and model axes. It carries supported, rejected and inconclusive outcomes forward to guide each new cycle. Across the 22-task Therapeutics Data Commons (TDC) ADMET benchmark, ADMET-EvO achieved the highest task-normalized score of 96.77. Evidence-guided selection reduced cumulative fitting time by 72.2% within a predefined non-inferiority margin. It also formalized 43 toxicity-related tasks and constructed endpoint-specific predictors. Together, these results show how ADMET-EvO can accumulate evidence, revise its strategy and expand its research scope over time.

## 二、方法论

### 2.1 核心思想

- **三层耦合架构：**
  - **任务层**：固定"在预测什么"（终点契约）。
  - **研究层**：决定"下一步做什么"（假设生成与行动选择）。
  - **证据层**：决定"所得数据究竟支持什么"（裁决与状态更新）。
- **关键设计约束：提案与裁决分离。** 语言模型只实例化规划策略 π（提出假设、在可行行动中选择），**绝不**实例化确定性评估器 E 或更新算子 U。智能体不能自行给出证据裁决、不能修改主指标或受保护的数据划分、不能把未完成实验提升为"支持"结论。即"智能体决定接下来获取什么证据，而由确定性评估器与更新规则决定所获证据支持什么"。

### 2.2 五阶段研究循环

1. **端点规范（Endpoint Specification）**：在建模决策前先确立测量边界，区分共享粗略 ADMET 标签但在生物靶点、语义、实验系统、物种、测量尺度、来源谱系或划分归属上不同的观测，防止"名义相关"的测量被无证据合并。
2. **认知画像（Epistemic Profiling）**：联合评估样本与骨架支持度、少数类计数、冲突测量、划分重叠、化学空间偏移、局部标签粗糙度、验证不稳定性和既有冻结性能，判断可建模性与可提升空间。22 个 TDC 任务中揭示：DILI、HIA、半衰期存在稀缺性；多个 CYP 任务存在类别不平衡；溶解度、清除率、hERG 存在数据冲突或划分重叠；DILI、生物利用度、HIA 存在显著化学空间偏移。
3. **假设分支（Hypothesis Branching）**：把画像综合为可证伪的解释，并指定解决该问题所需证据。
4. **多轴扰动（Multiaxial Perturbation）**：把每个优先不确定性转化为受控实验（研究行动）。
5. **证伪与精炼（Falsification & Refinement）**：以独立证据评估假设，分类为支持/拒绝/不确定，并更新下一轮循环。

### 2.3 形式化框架（关键公式与流程）

- **终点契约**：
  `C = ⟨y, assay, species, label, task, (m, dir), id, prov, split, ext⟩`
  固定预测目标、任务类型、主指标及其优化方向、分子身份约定、数据来源、划分归属与外部证据策略。后续所有推理均以 C 为条件。
- **研究状态**：
  `S_t = ⟨C, D_t, H_t, X, B_t⟩`
  其中 D_t 为当前数据诊断，H_t 为已执行干预的历史，X 为可用专家与工具，B_t 为剩余实验预算。
- **行动空间**：
  `a_t ∈ A_feature ∪ A_model ∪ A_data ∪ {replicate, stop}`
  复制与停止被视为控制动作，而非可优化的额外轴。
- **行动规格**：
  `a = ⟨τ, axis, c_ctrl, c_trt, m, seeds, budget, rule⟩`
  自由文本提案在解析为合法注册行动前不具有证据权重。
- **证据记录**：
  `e_t = E(a_t, S_t) = ⟨Δm_t, σ_t, c_t, status_t, cfg_t, prov_t⟩`
  包含效应量、不确定性/稳定性、计算成本、执行状态与完整配置与数据溯源；支持、不确定、被证伪、失败四类结果全部保留。
- **闭环**：
  `S_t → a_t → e_t → S_{t+1}`，由 π、E、U 驱动，直至 U 发出停止决策，输出保留配方及完整支持/反驳证据谱系。
- **配对效应与裁决**：
  `Δm_t(a) = (1/K) Σ_k Δm_t^(k)(a)`，`σ_t(a) = std_k[Δm_t^(k)(a)]`；在终点契约固定的指标下，确定性判定为 supported / refuted / inconclusive / failed。证据集更新为 `H_t^(n+1) = H_t^(n) ∪ {e_t(a)}`。

### 2.4 三轴干预的技术细节

- **数据轴**：仅改变训练证据或整理策略。候选分子经脱盐、中和、身份标准化；凡在标准化身份下匹配受保护（测试/验证/训练）分子的外部记录一律剔除（可捕获盐型、电荷、互变异构体变体）；外部
