## 摘要
传统的反应产率预测受限于缺乏显式空间信息的一维量子描述符。为解决这一不足，提出了一种双模态视觉交叉注意力架构，将表格化的物理有机数据与二维分子拓扑结构相融合。值得注意的是，我们证明了处理简单二维骨架结构的通用计算机视觉骨干网络本身就能胜过基于纯量子力学的方法。通过协同两种模态，最优的交叉注意力框架实现了优于传统方法的预测精度（测试集RMSE=5.27%）。通过机理探测，观察到主动的、描述符引导的空间查询，有效地将宏观位阻识别卸载到视觉通路。此外，网络学习了动态的化学层级，以高度优先处理关键位阻瓶颈，如芳基卤化物。同时，利用残差跳跃连接保护非空间电子参数在融合过程中免受破坏性衰减。总体来说，这为用深度视觉学习增强物理化学提供了一种可扩展且高度可解释的蓝图。

## Abstract
Traditional reaction yield prediction is constrained by 1D quantum descriptors that lack explicit spatial information. To address this gap, a dual-modal Vision Cross-Attention architecture is proposed, fusing tabular physical-organic data with 2D molecular topologies. Notably, it is demonstrated that a generic computer vision backbone processing simple 2D skeletal structures independently outperforms purely quantum-based baselines. By synergizing both modalities, superior predictive accuracy compared to traditional methodologies is achieved by the optimal cross-attention framework (Test RMSE = 5.27%). Through mechanistic probing, active, descriptor-guided spatial querying is observed, effectively offloading macroscopic steric identification to the visual pathway. Furthermore, a dynamic chemical hierarchy is learned by the network to heavily prioritize critical steric bottlenecks, such as the aryl halide. Concurrently, residual skip connections are utilized to protect non-spatial electronic parameters from destructive attenuation during fusion. Collectively, a scalable and highly interpretable blueprint is provided for augmenting physical chemistry with deep visual learning.

### 2. 方法论

**核心思想**：用显式物理有机表格数据（作为数学查询）主动检索通用视觉骨干从 2D 分子图提取的空间拓扑信息，实现"电子参数"与"位阻信息"的显式分工；并用残差跳连保护非空间量子特征不被注意力层破坏。

**2.1 双模态表示生成**

使用 Doyle Lab 的 rxnpredict 基准数据集（C–N 交叉偶联反应，含 DFT 计算表格描述符）。
- **表格描述符**：显式物理有机参数（HOMO/LUMO、偶极矩、Sterimol 等），经零均值单位方差标准化（仅用训练集拟合，防泄漏）。
- **2D 视觉拓扑**：用 RDKit 为每个反应组分（additive、aryl halide、base、ligand）独立生成 2D 骨架图，224×224 分辨率，RGB，用 ImageNet 标准归一化（非拼接到同一网格，而是独立图像、按组分顺序堆叠）。

**2.2 编码器**

- **表格通路**：MLP 将缩放后的表格描述符映射为维度 d=256 的嵌入向量 \(X_{tab}\)。
- **视觉通路**：ImageNet 预训练 ResNet-18（**参数完全冻结**，非化学领域预训练），四个组分图像分别处理，沿序列维叠加得到视觉嵌入矩阵 \(X_{vis} \in \mathbb{R}^{4 \times d_k}\)。冻结骨干以隔离并观察跨注意力学习动态。

**2.3 两种融合策略**

**策略 A：简单拼接（Simple Concat，基线）**
- 视觉特征经**无权重全局平均池化** \(X_{pool}=\frac{1}{4}\sum_{j=1}^{4} X_{vis,j}\)；
- 然后与原始表格特征拼接：\(X_{fused} = \text{Concat}(X_{pool}, X_{tab})\)；
- 送入 MLP 预测头。

**策略 B：多头视觉交叉注意力（冠军模型）**
- 表格特征 \(X_{tab}\) 作为 **Query**，视觉嵌入 \(X_{vis}\) 作为 **Key** 与 **Value**；
- 8 个独立注意力头（h=8），共享潜在维度 \(d_k=256\)，每个头独立投影：
  - \(Q_i = X_{tab} W_{Q,i}\)，\(K_i = X_{vis} W_{K,i}\)，\(V_i = X_{vis} W_{V,i}\)；
  - \(\text{head}_i = \text{softmax}(Q_i K_i^\top / \sqrt{d_k}) V_i\)；
  - 各头输出拼接后经输出投影 \(W^O\) 得到注意力上下文向量 \(X_{attn}\)；
- **关键设计——残差跳连**：\(X_{fused} = \text{Concat}(X_{attn}, X_{tab})\)，即注意力输出与原始未修改的表格特征拼接，避免注意力作为信息瓶颈破坏非空间电子参数；
- 最终经 MLP 预测头输出连续产率 \(ŷ\)。

**2.4 训练协议**

- 损失：MSE；优化器：AdamW（batch=32，初始学习率 1e-3，权重衰减 1e-4）；
- 学习率：余弦退火 + 热重启；训练 500 epochs，按验证集损失选取最优权重。

### 6. 主要结论与发现

- **通用视觉的意外效力**：无任何化学先验知识的 ImageNet 预训练 ResNet-18 仅凭 2D 骨架图，就能胜过依赖昂贵 DFT 描述的纯表格 MLP（5.60% vs. 6.80% RMSE），说明宏观位阻信息对反应产率的预测权重不低于电子状态信息。
- **简单拼接失效**：Simple Concat 的 RMSE（5.78%）反而比视觉单独（5.60%）更差，原因是**模态主导与捷径学习**——mean pooling 模糊了视觉局部细节，网络偏好从表格数字提取信号而非解译退化视觉特征。
- **交叉注意力机制**：以表格特征为 Query、视觉特征为 Key/Value，结构上强制模态间交互，避免了模态被忽略，达到最优 RMSE 5.27%。
- **特征依赖的结构性转向**：PFI 显示，Tabular MLP 高度依赖芳基卤化物的分子量（+9.38% RMSE 惩罚）作为位阻代理（因 1D 网络缺乏空间定位能力，只能迷信无噪声标量）；Cross-Attention 中分子量重要性完全消失，改由体积、表面积、椭圆度等几何描述符作为"空间查询指令"去索引 2D 图像，让视觉通路承担确认和定位位阻的职责，有效缓冲了 3D 构象噪声。
- **稀疏注意力与学习到的化学层级**：8 个注意力头的 softmax 分布呈极端稀疏二值化（中位数为 0），而非均匀池化；平均注意力预算中，**芳基卤化物占 53.27%**（中位数 0.5，即至少半数反应中该组分占据绝对多数视觉关注），**碱基几乎被压制**（均值 2.94%，75% 测试反应中被分配零注意力）。
- **残差瓶颈现象**：去掉残差跳连后 RMSE 从 5.27% 恶化到 6.17%，证明注意力层对非空间量子特征（偶极矩、HOMO 能级等）是破坏性信息瓶颈；残差连接是保护电子参数的数学必要条件。

### 7. 方法优点

- **通用骨干+冻结策略**：展示了"通用视觉 + 显式物理数学"的替代路径，挑战了化学深度学习必须领域预训练的假设，具备高度可扩展性；
- **天然可解释的注意力结构**：把视觉输入按组分 token 化（additive/aryl halide/base/ligand），使注意力权重可以逐组分解释，直接映射到化学直觉；
- **机制研究扎实**：将 PFI（特征归因）与注意力权重（内部路由）两大工具结合，对"双模态如何分工"给出了相互印证的证据链；
- **针对性的消融设计**：Simple Concat 作为"信息被稀释"的对照组，残差剪除作为"信息被过滤"的对照组，清晰地分离了两种失败模式（模态主导、注意力瓶颈）；

### 8. 不足与局限

- **原子级精度缺失**：ResNet-18 擅长宏观位阻，但无法定位微观官能团或过渡态精细几何。
- **对 DFT 的依赖未根本消除**：交叉注意力仍以 DFT 计算描述符作为 Query 锚点；对未见化学骨架的高吞吐筛选仍受 DFT 计算瓶颈限制。
- **2D 表示固有缺陷**：缺乏动态 3D 构象感知，难以建模强立体选择性反应路径。
- **数据与实验覆盖面局限**：仅一个

- **注意力解释的潜在风险**：softmax 稀疏化可能导致组分级归因过于二值化，掩盖同一组分内部不同区域/原子的细粒度贡献；且注意力权重不一定等于因果重要性。
- **未与化学专用视觉模型对比**：如 Chemprop、GNN 或分子图像 Transformer，无法确定通用视觉骨干是否真正优于领域特定架构。
