## 摘要
Transformer模型彻底改变了自然语言处理（NLP），而基于文本的分子表示如SMILES已成功将这些架构扩展到化学领域。然而，领域自适应预训练常常导致模型过度拟合化学语法，灾难性地遗忘其基础语义能力。为应对这一挑战，我们引入了CheMatE，一种面向化学的嵌入模型，在同一表示空间中联合捕获分子结构和领域特定的自然语言。CheMatE基于ModernBERT骨干，通过两阶段训练流程学习双语义表示：持续掩码语言建模（MLM），随后通过多重负排序损失（MNRL）进行Matryoshka对比学习阶段。首先，我们使用MLM在一个新颖的大规模SMILES注释长上下文科学文档语料库上训练模型，该语料库由FineWeb和ChemPile构建与整理（分别包含104亿和115亿个词元）。随后，模型使用从原始训练语料中算法推导出的合成SMILES-文本对数据集进行对比学习。这种设计使模型接触到富含SMILES的科学文献，从而实现双语义理解。我们在涵盖分子性质预测和科学语言理解的一系列下游任务上评估CheMatE。结果表明，将我们定制整理的语料库与这一顺序训练策略相结合，可产生稳健且高度可迁移的表示。通过在单一基于文本的框架内有效统一结构和上下文信号，CheMatE在专用化学模型和通用语言模型基线上均取得了有竞争力的性能。

## Abstract
Transformer models have revolutionized natural language processing (NLP), and text-based molecular representations like SMILES have successfully extended these architectures to chemistry. However, domain-adaptive pre-training often causes models to overfit to chemical syntax, catastrophically forgetting their foundational semantic capabilities. To address this challenge, we introduce CheMatE, a chemistry-oriented embedding model that jointly captures molecular structure and domain-specific natural language within the same representation space. Built on a ModernBERT backbone, CheMatE learns bi-semantic representations through a two-stage training procedure: continued masked language modeling (MLM) followed by a Matryoshka contrastive learning stage via Multiple Negative Ranking Loss (MNRL). First, we train the model using MLM on a novel, large-scale corpus of SMILES-annotated, long-context scientific documents that were constructed and curated from FineWeb and ChemPile (comprising 10.4B and 11.5B tokens, respectively). Subsequently, the model undergoes contrastive learning using a synthetic dataset of SMILES-text pairs algorithmically derived from our original training corpus. This design exposes the model to SMILES-enriched scientific literature, enabling bi-semantic understanding. We evaluate CheMatE across a range of downstream tasks covering molecular property prediction and scientific language understanding. Our results demonstrate that coupling our custom-curated datasets with this sequential training strategy yields robust, highly transferable representations. By effectively unifying structural and contextual signals within a single text-based framework, CheMatE achieves competitive performance across both specialized chemistry models and general-purpose language model baselines.

### 2. 方法论

#### 2.1 核心思想

- **双语义联合学习**：不将 SMILES 视为独立的"模态"，而是将其作为文本内联注释（inline annotation）直接嵌入自然语言句子中——在化学实体名称出现的位置插入对应的 SMILES 字符串。这使得 MLM 目标能同时建模"从文本上下文预测掩码 SMILES 词元"和"从 SMILES 词元预测文本上下文"的双向语义。
- **两阶段顺序训练**：
  1. **阶段一（MLM 持续预训练）**：在 SMILES 注释过的大规模科学语料上继续掩码语言建模（15% 掩码率）。
  2. **阶段二（Matryoshka 对比学习）**：使用合成 SMILES-文本配对数据，通过多重负排序损失（MNRL）配合 Matryoshka 维度截断损失，精炼嵌入质量。

#### 2.2 关键技术细节

- **数据筛选（TCS 评分）**：论文定义了文本化学评分（Text Chemistry Score, TCS），基于化学与非化学语料中的词频比值（`w_k = f_ck / f_nk`，阈值 10）对 FineWeb-Edu 文本打分，保留 TCS > 1 的文本，得到 104 亿词元的化学教育教学语料。
- **SMILES 注入管道**：四阶段自动化管道——(1) CDE2 进行化学命名实体识别（NER）；(2) OPSIN 进行 IUPAC 名称到 SMILES 的确定性转换；(3) PubChem API 作为 OPSIN 失败时的回退查找；(4) RDKit 进行规范化和价键校验。最终将有效 SMILES 字符串直接插入原文化学实体之后。
- **BalancedTokenBatchSampler（成本感知分布式批次采样器）**：针对现代 Transformer（如 ModernBERT）在**未填充（unpadded）**序列上使用 jagged attention 的训练模式，计算成本近似与 `Σ L²` 成正比。采样器同时施加三个约束：原始词元预算 `T_max`、填充后内存上限 `T_pad^max`、二次成本上限 `C_max`，配合 DDP 感知的分组策略，确保各 GPU 每次同步步的计算负载均衡。据作者报告，该方法将平均填充开销减少达 50%，在 8192 词元上下文下 GPU 利用率提升最高达 30%。
- **对比学习数据生成（算法 2）**：从注释语料中抽取文档并分块，以某个 SMILES 为锚点，用 Morgan 指纹（半径 2，2048 位）的 Tanimoto 相似度计算每个文本块与锚点的相似度（取块内最大），选出阈值 `τ+` 以上的 top-P 块为正样本、`τ−` 以下的 bottom-Q 块为负样本，形成三元组（anchor, positives, negatives）。
- **损失函数**：
  - 阶段一：标准 MLM 交叉熵损失：
    \[
    \mathcal{L}_{\text{MLM}}(\theta) = -\frac{1}{|\mathcal{M}|} \sum_{i\in\mathcal{M}} \log P_\theta(x_i \mid \tilde{X})
    \]
  - 阶段二：MNRL 损失（余弦相似度 + 交叉熵 + 批内负样本），并在多个截断维度（768, 512, 256, 128, 64）上加权求和，形成 Matryoshka 损失：
    \[
    \mathcal{L}_{\text{Matryoshka}} = \sum_{k=1}^{K} w_k \mathcal{L}^{(k)}_{\text{MNRL}}
    \]

#### 2.3 训练细节

- 基于 **ModernBERT-base** 架构，支持 8192 词元上下文。
- 阶段一：3 epoch，学习率 `5×10⁻⁴`，线性调度 + 1000 步预热，AdamW，BF16 混合精度，Flash Attention 2，16 块 GH200 GPU。
- 阶段二：在 100,000 个初始合成对中筛选出 19,638 对（锚点 SMILES 长度 ≥ 64 字符），以 20k 子集训练，3 epoch，学习率 `2×10⁻⁵`，500 步预热 + 余弦衰减，4 GPU，批大小 128（每 rank 16 + 梯度累积 2）。最终发布的是第一个对比学习 epoch 结束时检查点。

### 6. 主要结论与发现

- **联合表征可行**：CheMatE 在 SMILES 任务面板获得最低平均排名（1.9），在 NLP 面板也获得最低平均排名（3.2），是唯一同时进入两个模态 Nemenyi 最高统计等价组的化学专用模型。这证明结构理解与科学语义能力可以共存于单一编码器中。
- **双语义得分**：CheMatE 在 48 个数据集中有 43 个（87.8%）进入 Tukey HSD 最优统计组，加权双语义得分 **86.7%**，显著高于所有基线。
- **对比学习是关键**：仅 MLM 的中间检查点（CheMatE-MLM）在 SMILES 面板平均排名从 1.9 恶化至 6.6，双语义得分从 86.7% 降至 55.5%，说明第二阶段对比学习对嵌入质量精炼至关重要。
- **不存在模态权衡**：化学专用基线（MoLFormer、ChemBERTa、BERT-SMILES）在 NLP 面板均排名垫底（9.5-11.4 名），而 CheMatE 避免了这一语义权衡。
- **工程贡献有效**：BalancedTokenBatchSampler 在长上下文多 GPU 训练中显著减少填充开销并消除 OOM，支撑了 8192 词元上下文下的稳定训练。

### 7. 优点

- **大规模高质量数据管线**：提出了一套完整的大规模自动化 SMILES 注入流程（CDE2 → OPSIN → PubChem → RDKit），并从头构建了 1440 万文档、219 亿词元的双语义训练语料，这在化学 NLP 领域是稀缺资源。
- **成本感知的批次采样新方法（BalancedTokenBatchSampler）**：针对现代 Transformer 非填充训练中序列长度方差大的痛点，设计了同时约束 token 预算、内存上限与二次计算成本的调度器，有效提升了多 GPU 训练的利用率（最高 30%）并减少 50% 填充开销。该算法具有通用潜力，可推广到其他长文本编码器训练。

### 8. 不足与局限性

- **OPSIN/PubChem 转换的覆盖瓶颈**：尽管 SMILES 注入管道设计了四阶段回退机制，但 OPSIN 仅能处理 IUPAC 命名规则内的化合物名称，对商品名、通用名、缩写等非系统化学命名失效；当 CDE2 识别出的实体大量为这类名称时，需要依赖 PubChem API 查找，这使得 SMILES 注入的最终覆盖率高度受制于 NER 识别质量与外部数据库的收录范围。论文未报告最终文档级别的 SMILES 注入覆盖率，无法准确判断语料中真正带有化学结构注释的比例。
- **上下文窗口与长文本推理并未真正落地**：虽然模型支持 8192 词元上下文，但论文的 NLP 评估集中于**短文本分类或句子级回归**（如 ADE、PubMedQA、SciCite 等），并未在千词元级别的长文档任务（如长篇综述的篇章级关系分类、跨段落传导推理）上验证 8192 上下文窗口的实际收益。长窗口更多是训练阶段的工程特性，而非下游能力的实证。
- **冻结嵌入评估的单一性**：所有基准模型均以线性探针方式评估，未覆盖基于 CheMatE 的下游微调（fine-tuning on task-specific heads）。两者结论可能不同——微调可以修正预训练嵌入的偏置，也可能放大其缺陷；因此，"CheMatE 的嵌入更好"这一结论仅对固定表征场景成立，不能直接外推到微调范式。
- **对比学习数据筛选阈值过于依赖启发式**：正负样本的确定依赖 Morgan 指纹 Tanimoto 阈值（τ＋、τ−）与 top-P/bottom-Q 的数量选择，这些超参数缺乏敏感性分析。仅报告一个组合下的结果，读者无法判断双语义得分 86.7% 对阈值选择是否稳健。
- **Matryoshka 损失的重加权方式不透明**：各截断维度（768/512/256/128/64）的权重 w_k 如何设定、是否在训练中统一相等，论文未给出明确说明，也未分析不同维度截断下的性能退化曲线（除了最终嵌入 768 维的完整评估）。这使得 Matryoshka 对下游的实际增益未被充分验证。
- **训练成本信息缺失**：未报告总 GPU 小时数、数据构建的离线计算时间或 API 调用配额，对研究者在相似规模下的可重复投入缺乏参照系。
- **专有基线的可比较性存疑**：ChEmbed-Full 与 MoLFormer-c3-1.1B 等基线模型的训练细节、池化方式与嵌入维度差异未充分对齐；GTE-MLM 与 Nomic-MLM 作为通用模型在化学专用任务上排名靠后可预期，但论文未讨论这些模型训练语料与下游测试集的潜在重叠污染问题。
- **无法回答"为什么 SMILES 内的 MLM 有效"的机制问题**：论文证明了联合 MLM + 对比学习有效，但未提供从表征几何视角（如 SMILES 子词与语言词元的嵌入空间排列、注意力模式分析）解释其机制的实验，更多的是工程实证而非科学理解。

### 9. 个人思考与可能改进方向

- **从"插入文本"到"结构化交错"**：当前方法将 SMILES 作为纯文本 token 插入句子中，模型需要自己从顺序中恢复结构；如果引入显式的结构化注意力偏置（如对同一 SMILES 内的 token 施加相对位置编码或树形感知的注意力掩码），可能进一步增强模型对分子拓扑结构的归纳能力。
- **主动选择锚点分子**：对比学习部分仅选用 SMILES 长度 ≥ 64 的分子作为锚点，这天然偏向复杂大分子；小分子（如药物先导物）的文本-结构对齐质量未得到验证。可探索按分子量、骨架多样性分层抽样的锚点选择策略。
- **多模态验证的延展**：CheMatE 目前只统一了 SMILES 与自然语言两个模态。在材料、蛋白质、化学问答场景中，类似的双语义注入思路可直接迁移到蛋白质序列（氨基酸序列）与文本的联合建模；其对比学习框架本身与模态无关，推广空间较大。
- **潜在实践价值**：Matryoshka 设计使其在资源受限的部署环境下可按需降维，这意味着在移动端或边缘设备的化学文献检索、专利筛选、化合物-文本混合检索系统中具备落地潜力。若能补充一套长文本检索/排序的实际案例，将更具说服力。

### 整体评价（一言之蔽）

CheMatE 在工程完整度、数据规模与统计严谨性上都达到了化学 NLP 前沿水准，用"文本内联 SMILES + 两阶段训练"巧妙绕开了结构—语义的模态对立，并给出了令人信服的实证证据。它最大的贡献不在于某个 SOTA 刷新，而在于证明了**化学结构表达与科学语言理解可以在单一编码器中无权衡共存**——这为材料、药物、蛋白质等跨学科领域的统一表征研究铺设了一条可复用的方法路径。但其短板同样明显：机制层面缺乏解释性实验、对比学习超参数敏感性未知、长上下文能力未在下游实证、以及训练成本信息缺失，都留待后续工作充实。
