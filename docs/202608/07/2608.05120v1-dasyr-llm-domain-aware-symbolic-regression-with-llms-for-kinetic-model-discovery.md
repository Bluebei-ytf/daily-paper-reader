## 摘要
动力学模型发现是化学工程中的一个核心挑战，因为准确的速率表达式对于理解和控制化学与生物过程至关重要。符号回归（SR）已成为识别可解释动力学模型的一种强大数据驱动方法，但它通常在没有领域知识的情况下运行，经常探索物理化学上不合理的模型。大语言模型（LLM）为将领域专业知识注入这一搜索过程提供了有前景的途径。在此，我们引入了一个LLM引导的SR框架，将LLM模块嵌入迭代SR算法中，以实现自动化动力学模型发现。LLM在每次迭代中扮演两个角色：（1）对最佳SR候选模型进行定性物理化学评述；（2）在SR生成模型和内置化学知识的指导下提出新的候选速率表达式。我们在四个复杂度递增的计算机模拟案例研究中评估了该框架，涵盖多相催化和生物过程系统。结果表明，与最先进的SR框架相比，LLM引导框架将识别真实模型所需的迭代次数减少了41.7%至79.3%，并且在超过一半的引导运行中，LLM直接提出了正确的模型结构。在实际场景中，每次迭代通常需要一次新的湿实验，这意味着实验工作量的大幅减少。两种方法在独立验证集上的预测性能相当，所有案例研究的R²>0.98。消融研究表明，SR组件和LLM规模都对这一性能有所贡献，而缩小规模的LLM在很大程度上保持了发现效率。这些发现证明，LLM能够有效地将领域知识注入科学模型发现过程，为全自动、领域感知的动力学建模流程铺平了道路。

## Abstract
Kinetic model discovery is a central challenge in chemical engineering, as accurate rate expressions are essential for understanding and controlling chemical and biological processes. Symbolic regression (SR) has emerged as a powerful data-driven approach for identifying interpretable kinetic models, but usually operates without domain knowledge, often exploring physicochemically implausible models. Large language models (LLMs) offer a promising avenue for injecting domain expertise into this search. Here, we introduce an LLM-guided SR framework, embedding an LLM module within an iterative SR algorithm for automated kinetic model discovery. The LLM performs two roles at each iteration: (1) a qualitative physicochemical critique of the best SR candidates, and (2) the proposal of new candidate rate expressions guided by the SR-generated models and embedded chemical knowledge. Our framework is evaluated on four in silico case studies of increasing complexity, spanning heterogeneous catalysis and bioprocess systems. Results show the LLM-guided framework reduces iterations to identify the ground-truth model by $41.7-79.3\%$ versus a state-of-the-art SR framework, with the LLM directly proposing the correct model structure in over half of the guided runs. In practical settings, where each iteration typically requires a new wet-lab experiment, this translates into a substantial reduction in experimental effort. Predictive performance on an independent validation set is equivalent between both approaches, with $R^2>0.98$ in all case studies. Ablation studies indicate that both the SR component and the LLM scale contribute to this performance, with a reduced-size LLM largely retaining discovery efficiency. These findings demonstrate that LLMs can effectively inject domain knowledge into scientific model discovery, paving the way toward fully automated, domain-aware kinetic modelling pipelines.

## 2. 方法论

### 核心思想
- 使用 ADoK-S（一种结合 SR、参数估计、AIC 模型选择和多目标实验设计的迭代发现框架）作为基础 SR 骨干；
- 在每一轮迭代中嵌入一个 LLM 模块，由 LLM 完成两项任务：
  1. 对 SR 生成的最佳候选速率表达式进行定性物理化学评述；
  2. 在此基础上，结合自身的化学/物理知识提出若干新的候选速率表达式；
- 新旧候选统一接受参数估计和 AIC 排名，然后由 MBDoE 设计下一轮实验，从而形成闭环。

### 主要流程（九步）
- 步骤 1–2：由已知的真实系统生成含噪声的浓度数据，并用 SR（PySR）拟合每个物种的浓度-时间轨迹；
- 步骤 3–4：利用 AIC 选出最佳浓度轨迹表达式，并对轨迹解析求导得到反应速率估计值；
- 步骤 5–6：对估计的速率进行 SR 搜索候选速率定律，并通过 ODE 积分和 L-BFGS-B 多起点优化（20 个随机起点）精修参数；
- 步骤 7：LLM 模块（图 1 核心环节）：
  - 先对 top-5 SR 候选进行“模型批判”，评估其结构、参数量级、机理合理性和可解释性；
  - 再提出 3 个新候选表达式；论文并行运行 3 个 LLM 实例，故最多产生 9 个新候选；
  - LLM 使用的是 Qwen3-14B，开启 thinking 模式，温度 0.6、top-p 0.95、top-k 20；
- 步骤 8：所有候选（SR 生成 + LLM 生成）计算 AIC，并选择最优模型；若找到真实结构或预算耗尽即终止；
- 步骤 9：若未收敛，则用 AIC 排名前两的模型执行 MBDoE，通过最大化两者预测轨迹的平方差（Hunter-Reiner 准则）来设计新的初始条件实验，扩充训练集。

### 关键设计细节
- 两阶段 SR：先用 SR 拟合浓度轨迹，再对轨迹导数拟合速率定律，避免在 SR 内进行昂贵的动态参数优化；
- 参数估计：利用 ODE 积分将速率模型映射回浓度空间后拟合参数；
- 模型选择：基于负对数似然（NLL）和 AIC，兼顾拟合优度与模型复杂度；
- LLM 输出采用自由文本，由人工手动解析为结构化表达式；
- 确定性指标：95% 置信区间、p 值检验参数显著性；
- 独立验证集：包含内部点、边界点、适度外推（+20%）、激进外推（+50%）。

- 主实验：4 案例 × 2 算法 × 4 次重复 = 32 次发现流程运行；
- 消融实验：细菌蛋白生产案例上共 8 次运行（LLM-Only 无数据 2 次、LLM-Only 有数据 2 次、Qwen3-8B 4 次），加上主实验超过 40 次完整的发现循环；
- 每个案例均在 120 个独立验证条件下计算 R²、MAE、MSE；
- 还对每次收敛模型的所有参数做了 95% 置信区间和显著性检验。

### 充分性与客观性评价
- 多样性：四个案例覆盖催化、可逆异构化、生物反应，结构复杂度差异明显，主实验重复 4 次，考虑了随机影响；
- 公平性：两种算法共享相同初始数据集、实验预算、噪声水平、验证集和指标，使迭代次数可比；
- 消融设计较好：区分了 SR 组件贡献和 LLM 规模影响，并额外考察了 LLM 是否有数据访问的边界情形；
- 局限性：均为合成数据，未在真实湿实验平台上验证；三个文献案例可能已存在于 LLM 预训练语料中，存在记忆偏倚；论文作者也承认无法完全排除上述风险。

## 6. 主要结论与发现

- 与 Baseline SR 相比，LLM-guided SR 将识别真实模型（或等效模型）所需的迭代次数减少 41.7%–79.3%；
- 在 16 次 LLM-guided 主运行中，9 次最终模型由 LLM 直接提出，说明 LLM 不仅是“加速器”，还可主动生成正确结构；
- 独立验证集上，所有案例、两种算法的 R² 均高于 0.98，预测性能相当，说明迭代减少并未带来精度损失；
- 改进幅度最大的案例是 N₂O 分解和细菌蛋白生产，即基线 SR 最困难的结构；
- 消融结果表明：
  - 完全移除 SR 后，LLM 独立发现的可靠性下降（无数据时 2 次中 1 次未收敛）；
  - Qwen3-8B 仍能全部收敛（2–5 次迭代），表明框架对小模型韧性强，但样本量少；
- 作者认为 LLM 有效地将化学领域知识注入模型发现循环，能为自动化、领域感知的动力学建模提供新途径。

## 7. 优点

- 方法设计模块化：LLM 只负责评述和提出候选，不干扰 SR 和 MBDoE，便于独立替换或升级；
- 将“定性物理化学合理性”显式纳入模型选择，弥补了传统 SR 仅依赖统计准则的不足；
- 与 MBDoE 闭环结合，使发现的每个迭代对应一次实验设计，直接体现“减少实验成本”的实际价值；
- 在多个跑次中，LLM 能够识别 SR 候选中的机理缺陷（如逆基质的非物理依赖）并给出可解释的改进表达式；
- 对运行中的 LLM 提示、配置、参数估计和验证集都做了较详尽描述，代码开源，可复现性较好；
- 补充了较完整的参数不确定性分析（置信区间、p 值），增强发现模型的统计可信度。

## 8. 不足与局限

- 未在真实实验数据上测试：所有案例均为合成数据，假设所有物种可测且噪声为高斯零均值，未考虑系统偏差、缺失变量或更复杂的误差结构；
- 人工解析 LLM 输出：当前管线仍需人工将 LLM 的自由文本表达式转换为可执行符号形式，并未实现“全自动闭环”，规模化应用受限；
- 每轮计算成本高于基线，LLM 推理和 LLM 候选的参数估计占用大量时间，在实验成本不高的场景下优势有限；
- 参数估计不保证全局收敛，LLM 候选缺乏初始参数，可能因劣质初始化而在 AIC 排名中落选，影响收敛；

- LLM 的领域知识受到预训练语料覆盖范围的限制：对文献稀疏或机理新颖的反应体系，LLM 可能提出陈旧甚至错误的先验结构；同时论文未对 LLM 输出的置信度做定量评估，也未设计当候选完全不可用时的降级或容错机制；
- MBDoE 仅将初始条件作为实验设计变量，未同时优化温度、压力、停留时间等其他可调操作条件，限制了在实际化工流程中实验空间利用的灵活性；今后可扩展为多变量联合设计；
- 收敛判据依赖“已知真实模型”这一设定：在真实发现任务中无法预知速率定律的真实结构，需要另设间接指标（如验证集误差饱和、AIC 连续多轮不下降等）来停止迭代；
- 案例均为低维 ODE 系统（最多 2–3 个状态变量），未验证在高维、强耦合或存在不可观测内源变量时的扩展性，而后者在生物过程和复杂催化网络中十分常见。

总体上，本文提出的 DASyR-LLM 框架将领域知识以低成本、可插拔的方式注入 SR–MBDoE 闭环，在明显减少实验轮次的同时保持了统计精度和模型可解释性，为“知识驱动 + 数据驱动”的动力学模型发现提供了一个有前景的范式。但离端到端全自动发现仍有距离，LLM 输出解析、实验空间扩展、真实湿实验验证以及收敛准则自适应等问题，是后续需要重点攻克的环节。
