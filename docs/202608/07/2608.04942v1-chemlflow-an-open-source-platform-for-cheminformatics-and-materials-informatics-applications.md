## 摘要
CheMLFlow是一个开源平台，用于构建和执行面向科学和技术应用的端到端、高通量及智能体驱动的工作流。CheMLFlow针对科学机器学习开发中的一个常见瓶颈：研究人员往往需要将数据采集、整理、表示、模型训练、验证、筛选、解释和报告组装成可复现的流水线，即使其主要研究贡献仅涉及其中一个阶段。CheMLFlow提供模块化的工作流组件、即用型参考流水线、标准化产物和评估输出，从而减少编排开销并支持跨方法和数据集的基准测试。该平台设计为可扩展、可复现且易于自动化，具有可插拔的表示和模型、确定性数据划分、显式运行产物、批量执行和报告生成功能。随着科学软件日益向智能体辅助实验方向发展，CheMLFlow的配置驱动工作流和结构化输出也为编码智能体提供了一种实用接口，帮助用户在人工监督下构建实验、检查结果并总结发现。本文描述了系统架构、核心工作流以及达到文献性能的量子力学、物理化学和生物活性性质预测基准，并展示了涉及时间序列数据集的应用案例，证明了其应用范围不仅限于分子化学数据集。

## Abstract
CheMLFlow is an open-source platform for building and executing end-to-end, high-throughput, and agentic workflows for scientific and technological applications. CheMLFlow targets a common bottleneck in scientific machine learning development, where researchers often need to assemble data acquisition, curation, representation, model training, validation, screening, interpretation, and reporting into a reproducible pipeline, even when their primary research contribution concerns only one stage. CheMLFlow provides modular workflow components, ready-to-run reference pipelines, standardized artifacts, and evaluation outputs that reduce orchestration overhead and support benchmarking across methods and datasets. The platform is designed to be extensible, reproducible, and automation friendly, with pluggable representations and models, deterministic splits, explicit run artifacts, batch execution, and report generation. As scientific software increasingly moves toward agent assisted experimentation, CheMLFlow's configuration driven workflows and structured outputs also provide a practical interface for coding agents to help users construct experiments, inspect results, and summarize findings under human supervision. This article describes the system architecture, core workflows, and benchmarks that reach literature performance for quantum mechanical, physicochemical and bioactivity property prediction, and use cases involving time series datasets demonstrating applications beyond molecular chemistry datasets.

- **核心瓶颈**：科学机器学习（ML/AI）开发中，研究者即使只专注于某一环节（如新模型、新表征或新数据集），也必须将数据获取、整理、表示、模型训练、验证、筛选、解释和报告等所有阶段组装为可复现的流水线，这种重复的“编排开销”严重拖慢迭代速度、使公平比较复杂化，并导致复现困难。
- **现有工具的不足**：当前多数工具（如ChemCrow、Co-Scientist、El Agente）聚焦于单一建模或设计任务，缺少端到端工作流支持、系统级可复现性和跨方法/数据集的系统性基准测试能力。
- **CheMLFlow的定位**：一个开源、模块化、可扩展的配置驱动平台，帮助非专家用户直接构建完整工作流，同时允许专家研究者聚焦于单个环节（数据生成、表示或模型开发），并以标准化的运行产物支持可审计的基准测试和智能体辅助科学计算。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：将科学ML工作流抽象为一系列显式、模块化的流水线节点，每个节点读取上游产物、写入自己的结构化输出，以“完整工作流配置”而非“单个模型名称”作为基准测试的基本单位。
- **三层架构**：
  - **核心工作流构建层**：从数据生成/获取到报告生成的端到端（或节点到节点）流水线，每个节点可在多种选项中选择。
  - **实验设计（DOE）层**：在多个节点上同时选择多种选项，自动展开组合实验网格，生成排行榜式的性能指标汇总。
  - **智能体（Agentic）层**：通过自然语言或技术指令，帮助用户设置工作流和DOE、生成报告、优化流水线，最终决策由人类研究者掌控。
- **工作流配置**：通过单个YAML或JSON文件定义数据集来源、任务类型、目标列、流水线节点、整理设置、划分策略、分子表示、预处理选项、模型类型和输出位置；重新执行同一解析配置（相同随机种子和软件环境）可复现相同流水线结构和划分定义。
- **运行产物契约**：每次运行产生一组标准化制品，包括解析后的运行配置、状态文件、划分元数据、指标文件、预测文件、序列化模型、图表（回归的parity图、分类的ROC/PR/混淆矩阵、SHAP/置换重要性图）及DOE聚合分析表。
- **DOE基准协议**：DOE规范将网格/模型搜索定义展开为大量具体运行配置，每个案例独立执行并记录状态；失败案例保留为失败记录而不被转化为虚假指标，成功运行聚合为父级摘要，保证无效输出不污染比较表。
- **Agent技能（Agent Skills）**：提供简短、带版本的操作指南，帮助编码智能体（如Codex）生成有效配置、启动运行、定位输出、执行分析和向人类用户解释结果。

## 3. 实验设计

### 3.1 生物活性预测（ChEMBL）
- **目标与数据**：从ChEMBL数据库获取4个靶标的IC50数据并转换为pIC50：PDE4B/CHEMBL275、EGFR/CHEMBL203、hERG/CHEMBL240、ALK-5/CHEMBL4439。
- **方法**：Morgan指纹与RDKit描述符作为表征，使用随机5折交叉验证和骨架（scaffold）5折交叉验证两种划分策略，训练随机森林、SVM、集成模型等并报告R²、RMSE、MAE。
- **基准对比**：以文献报告模型作为对比参照——PDE4B的AutoML集成模型（R²=0.85）、EGFR的随机森林（R²≈0.72）、ALK-5的DNN（R²=0.66）、hERG的Pred-hERG 5.0回归模型（R²=0.61，RMSE=0.48）。

### 3.2 跨领域分子性质基准（6个数据集）
- **数据集**：QM9（量子力学HOMO-LUMO能隙，133,885个分子）、Pgp（P-糖蛋白抑制，分类）、ARA（雄激素受体拮抗剂，分类）、Flash（闪点回归）、YSI（烟炱指数回归）、PAH（多环芳烃log回归）。
- **实验网格**：11种ML/DL模型 × 2种特征输入（RDKit描述符、Morgan指纹）× 3种scaler（minmax、standard、none）× 2种划分策略（随机、scaffold）= 132个聚合运行，外加Chemprop和CheMeleon两种SMILES-native图神经网络基线×2种划分=4个聚合运行，共136个父级作业。
- **对比方法**：决策树、SVM、随机森林、XGBoost、集成模型、DL-simple、DL-deep、DL-autoregression、DL-GRU、DL-tab transformer、DL-residual MLP，以及Chemprop和预训练CheMeleon基线。

### 3.3 智能体辅助工作流评估
- **任务**：QuantumScents气味预测——将多标签数据二值化为“果味”的一对多分类任务。
- **实验1（无CheMLFlow）**：独立代理使用XGBoost+ECFP4+RDKit描述符，5折CV的ROC-AUC为0.88。
- **实验2（使用CheMLFlow）**：代理执行scaffold 5折CV研究，DOE包含9种模型/特征组合（45次训练运行），扩展后为26种组合（130次训练运行），并加入ECFP4+RDKit组合特征与分层随机CV分支。
- **关键复现校验**：发现随机CV下最佳模型ROC-AUC为0.88（匹配独立代理），而scaffold CV下降至0.83，暴露了独立基准无法揭示的泛化差异。

### 3.4 时间序列预测
- **数据**：Mackey-Glass混沌时间序列（a=0.2, b=0.1, n=10, τ=17），添加0%、10%、20%、30%的高斯噪声。
- **模型**：Adaptive NVAR（自适应非线性向量自回归），预测步长25/50/75/100，对比原Adaptive NVAR论文报告结果。

## 6. 主要结论与发现

- **平台实用性**：CheMLFlow能在公共生物活性数据上快速生成透明、可审计、文献可比的基线研究——PDE4B达到R²=0.82（文献0.85），EGFR达到R²=0.70（文献约0.72），ALK-5超出文献DNN（R²=0.69 vs 0.66），hERG提供实用的保守基线（R²=0.52 vs 0.61）。
- **跨领域泛化**：单次DOE实验在QM9（MAE=0.0047 vs Uni-Mol 0.0043）、Pgp（AUC=0.90 vs MLP 0.95）、ARA（AUC=0.90 vs DeepAR 0.95）、Flash（R²=0.94 vs 0.92）、YSI（MAE=22.3 vs 19.17）、PAH（R²=0.96 vs 0.96）上均达到或接近文献性能。
- **表征/模型/划分策略强依赖**：传统RF/XGBoost/集成方法在中小数据集上优于DL模型；图神经网络在大数据集上更优；随机划分性能优于scaffold划分，但scaffold划分反映真实应用中的系列外推能力，推荐用于可迁移模型。
- **Agent辅助有效且更严谨**：CheMLFlow的agent技能使智能体在同等ROC-AUC下获得更科学的实验设计——显式验证策略暴露了随机CV到scaffold CV约0.05 AUC的差距，这是独立agent基准无法揭示的。
- **时间序列扩展**：CheMLFlow的Adaptive NVAR模块在Mackey-Glass混沌时间序列上达到与原论文相当的预测性能，证明平台可超越静态分子数据场景。

## 7. 优点与亮点

- **模块化工作流抽象**：将科学ML过程建模为显式节点和标准化产物，使“完整工作流”而非“模型名称”成为基准单位，大幅降低编排负担。
- **可复现性设计**：确定性划分、解析配置保存、配置hash、git hash、失败元数据记录，支持精确复现和审计。
- **DOE层次化高吞吐**：网格展开到独立运行、成功/失败分开处理、父级聚合汇总，避免无效输出污染指标表。
- **双划分评估策略**：同时报告随机CV（内插性能）和scaffold CV（系列外推能力），避免化学类似物泄漏带来的乐观估计。
- **Agent友好架构**：结构化产物+agent技能使编码智能体可以安全地执行安装、配置、运行、检查、总结等操作，且人类保留解释权和最终决策权。
- **超越分子科学的可扩展性**：时间序列模块证明节点抽象可泛化到其他科学数据模态。
- **开源生态友好**：支持本地CLI、HPC调度器、外部编排工具，集成Optuna超参数优化。

## 8. 不足与局限

- **实验覆盖面与生产完备性**：平台未覆盖所有文献模型架构、描述符集和优化协议（作者明确承认）；ChEMBL研究是“文献相邻”基线而非精确复现，可比性受ChEMBL版本、assay过滤、超参数差异等因素限制。
- **未进行超参数优化**：所有报告性能来自“单次DOE实验”而非HPO后的最佳结果；作者虽提及平台支持Optuna，但已展示实验中未启用，对部分数据集的性能可能造成低估。
- **SOTA对比有限**：对比基准为文献报告值而非统一的复现实现，无法排除实现/调参差异对比较公平性的影响；未与更多近期SOTA进行同等条件下的全面对比。
- **scaffold划分性能下降风险**：某些数据集（如hERG在scaffold CV下R²仅0.36）泛化性能明显偏低，可能限制实际应用价值。
- **计算资源信息不透明**：未披露具体GPU型号、数量、训练时长、能源消耗等关键信息，影响他人对平台部署成本的实际评估。
- **应用边界**：当前工作以分子/小分子数据为主，虽展示时间序列案例，但材料信息学“周期性系统”等真正目标尚未验证（文中列为未来工作）；对药物发现/材料设计中更复杂的逆设计、多目标优化等场景支持有待证明。
- **CheMeleon基线设置限制**：预训练编码器被冻结、仅训练回归头，未评估微调时的潜在性能提升。
