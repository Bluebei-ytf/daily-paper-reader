## 摘要
从红外（IR）光谱推断分子结构是一个基本但具有挑战性的问题。一个关键难点在于，红外光谱提供的结构信息有限：不同的分子可能共享相似的官能团和局部振动模式，导致光谱响应高度相似。因此，即使观察到的光谱具有独特的潜在结构，从光谱中重建该结构仍然存在模糊性。现有的红外到分子（IR-to-molecule）模型通常生成一组排序的候选分子，但这组候选在很大程度上由模型学习到的生成偏好决定，可能无法完全捕获最能满足观测光谱约束的结构。为了解决这一局限性，我们提出了SpecCal，一种用于红外到分子预测的免训练候选校准框架。SpecCal作用于现有基础模型的候选输出，通过重新排序当前候选，并根据光谱一致性引入额外的结构上合理的备选方案来改进预测集。该框架即插即用且与模型无关，无需更新参数即可与各种基础模型集成。多个基准实验表明，SpecCal在不同基础模型上一致地提高了SMILES和支架（scaffold）级别的top-k重建性能。进一步的分析表明，在光谱模糊性下校准候选集为改进从红外光谱进行分子重建提供了一种实用方法。代码可在以下网址获取：https://anonymous.4open.science/r/SpecCal-B18A。

## Abstract
Inferring molecular structures from infrared (IR) spectra is a fundamental yet challenging problem. A key difficulty is that an IR spectrum provides limited structural information: different molecules may share similar functional groups and local vibrational patterns, leading to highly similar spectral responses. Thus, even when an observed spectrum has a unique underlying structure, reconstructing it from the spectrum remains ambiguous. Existing IR-to-molecule models usually generate a ranked set of candidate molecules, but this set is largely determined by the model's learned generation preference and may not fully capture the structures that best satisfy the observed spectral constraints. To address this limitation, we propose SpecCal, a training-free candidate calibration framework for IR-to-molecule prediction. SpecCal operates on the candidate outputs of existing base models and improves the prediction set by re-ranking current candidates while introducing additional structurally plausible alternatives guided by spectral consistency. The framework is plug-and-play and model-agnostic, requiring no parameter updates for integration with diverse base models. Experiments on multiple benchmarks show that SpecCal consistently improves top-k reconstruction at both SMILES and scaffold levels across different base models. Further analyses demonstrate that calibrating candidate sets under spectral ambiguity provides a practical way to improve molecular reconstruction from IR spectra. The code is available at: https://anonymous.4open.science/r/SpecCal-B18A.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务定义**：IR-to-molecule 预测，即从红外（IR）光谱推断分子结构（SMILES 序列）。红外光谱具有非破坏性、快速、低成本等优势，相比 NMR 和 MS 更适合大规模自动化分子结构鉴定。
- **核心难点——光谱模糊性（Spectral Ambiguity）**：IR 光谱提供的结构信息有限，不同分子可能共享相似的官能团和局部振动模式，从而产生高度相似的光谱响应。因此，即使观测光谱对应唯一真实结构，从其重建分子结构仍然存在内在歧义。
- **现有方法的不足**：现有编码器-解码器（如 Transformer）模型在推理时通常采用基于似然的解码策略（如 beam search）生成排序候选集。但在光谱模糊性下，似然排序不可靠地反映光谱一致性——高排名候选可能与观测光谱对齐不佳，而低排名候选反而更满足光谱约束；此外，候选集受模型生成偏好主导，可能完全遗漏最符合光谱约束的结构。
- **研究意义**：本文提出了一个训练-free、模型无关的候选校准框架 SpecCal，通过对现有模型输出的候选集进行"重排序 + 探索补充"，在不重新训练模型的前提下提升分子结构重建的准确率与多样性。

## 2. 方法论：核心思想、技术细节与算法流程

### 2.1 总体框架
- SpecCal 以现有 IR-to-molecule 基础模型（如 IR2Mol、Patch Transformer、CoCa）生成的候选集为起点，在测试时进行校准，从两个互补方面改进最终预测集：
  1. **重排序（Re-ranking）**：按光谱一致性重新排列已有候选；
  2. **探索补充（Exploration）**：引入未在基础模型初始候选中出现、但光谱上合理的新结构。
- 整个校准过程由 **蒙特卡洛树搜索（MCTS）** 实现，该算法天然平衡"探索新候选"与"利用高光谱一致性候选"。

### 2.2 搜索空间形式化
- 将分子细化建模为 SMILES 序列的局部编辑过程：
  - $y^{(t+1)} = \mathcal{E}(y^{(t)}, \delta^{(t)})$，其中 $\delta^{(t)}$ 为局部编辑，$\mathcal{E}$ 为编辑后自回归补全。
  - 目标函数：$y^* = \arg\max_y \mathcal{S}(y, s)$，其中 $\mathcal{S}$ 为光谱一致性分数。

### 2.3 MCTS 四阶段（伪代码见 Algorithm 1）
1. **选择（Selection）**：从根节点递归选择 UCB 分数最高的子节点：
   $$\text{UCB}(z) = Q(z) + C\sqrt{\frac{\ln N(p(z))}{N(z)}}$$
   其中 $Q(z)$ 为节点价值，$N(z)$ 为访问次数，$C$ 为探索/利用权衡常数。
2. **扩展（Expansion）**：采用**不确定性感知扩展策略**——用香农熵估计当前 SMILES 各 token 位置的模型预测不确定性，选取最不确定位置，从预测分布中采样 $N_c$ 个候选 token，保留前缀、替换该 token 后自回归补全生成 $N_e$ 个完整候选：
   $$y_k^{(t+1)} \sim p_\theta(\cdot \mid y_{<i^*}, \tilde{y}_{i^*,k}, s)$$
3. **评估（Evaluation）**：用先验 IR 预测器（Chemprop-IR，基于 D-MPNN）从候选分子预测光谱 $\hat{s} = f_{IR}(y)$，再计算光谱信息散度（SID）并转换为有界奖励：
   $$\mathcal{S}(y,s) = \frac{1}{1 + \text{SID}(\hat{s}, s)}, \quad \text{SID}(\hat{s},s) = \sum_i \hat{s}_i \log\frac{\hat{s}_i}{s_i} + s_i \log\frac{s_i}{\hat{s}_i}$$
4. **反向传播（Backpropagation）**：沿选择路径更新各节点的统计量 $N(u)$ 与 $Q(u)$。

### 2.4 终止与多样性感知候选选择
- 达到最大迭代次数或找到高奖励节点后终止搜索。
- 使用 **最大边际相关（MMR）** 从候选池中选出最终 top-K，兼顾奖励与多样性：
  $$\text{MMR}(y) = \lambda \cdot \hat{r}(y) + (1-\lambda)\cdot\left(1 - \max_{y' \in \mathcal{Y}} \text{sim}(y, y')\right)$$
  其中 $\text{sim}$ 为分子指纹的 Tanimoto 相似度，$\lambda$ 控制奖励与多样性的权衡。

### 2.5 关键特点
- **免训练（training-free）**：无需更新基础模型参数，仅增加推理期计算。
- **即插即用、模型无关**：可适配任意 Transformer 类 IR-to-molecule 基础模型。

## 6. 主要结论与发现

- **一致提升**：SpecCal 在所有数据集和所有基座模型上均显著提升 top-1/top-5 命中率，并带来 top-10 的进一步改善。例如：IR2Mol 在 NIST 的 SMILES top-1 从 37.1% 提升至 54.4%；CoCa 在 SynSet 的 top-1 从 21.3% 提升至 47.9%。
- **增益集中在 top-1/top-5**：说明 SpecCal 的核心作用是将光谱一致性更高的结构重新排到前列，而非单纯扩大候选池。
- **探索价值显著**：CoCa 的 top-10 改善比 IR2Mol/Patch Transformer 更明显，说明当基础模型较弱时，SpecCal 能挖掘出原本未被优先考虑甚至缺失的正确结构。
- **scaffold 级别同样提升**：表明方法不仅恢复精确 SMILES，还能改善分子骨架层面的重建。
- **多样性大幅提升**：所有模型的候选集 Tanimoto 相似度显著下降、scaffold 多样性显著上升，例如 Patch Transformer 在 NIST 的 Tanimoto 从 0.5946 降至 0.1677。
- **深度/规模分析**：树深度从 4 增至 5 时多样性显著改善后趋于稳定；有效节点数与多样性正相关。
- **案例验证**：对于基座模型 top-10 完全缺失真实结构的样本（GT: CCCCCC=CCCC=O），SpecCal 通过谱一致性引导搜索将真实结构引入候选集并排至第 5 位。

- **创新视角**：首次明确提出并针对 IR-to-molecule 的"光谱模糊性"问题，将问题从"生成更好模型"转向"测试时校准候选集"，思路新颖。
- **即插即用与模型无关**：无需重训练、不改变架构，可直接集成到任意现有 IR-to-molecule 模型，实用价值高。

- **奖励设计合理**：利用预训练的 Chemprop-IR 作为前向光谱预测器，以 SID 转为平滑有界奖励，信号信息量大；消融实验证明其关键作用。

- **光谱多样性覆盖有限**：仅使用气相 IR 光谱（NIST）和模拟光谱（SynSet），未涉及凝聚相、溶液或其他实验条件的光谱；合成光谱与实验光谱之间的域差异可能影响 Chemprop-IR 奖励的可靠性。

## 8. 不足与局限（续）

- **对比基线不够全面**：未与多样化 beam search、重打分（re-scoring）等替代性测试时解码策略进行系统比较。由于 SpecCal 的增益可能部分来自“更多候选”或“更多样的候选”，而非 MCTS 本身的搜索机制优势，缺少此类对照使得方法的边际贡献难以精确归因。
- **奖励模型的误差传递**：SpecCal 的核心奖励依赖 Chemprop-IR 预测光谱的质量。如果 Chemprop-IR 对某类官能团或分子骨架的光谱预测存在系统性偏差，SpecCal 的排序和探索将同样受到影响。论文仅在消融中对比了“无 Chemprop-IR”与“有 Chemprop-IR”的差距，未分析 Chemprop-IR 预测误差与 SpecCal 最终性能之间的相关性。
- **候选集质量的上限依赖**：重排序效果受初始候选集质量制约。若基础模型的 beam search 输出完全不含与观测光谱一致的结构，SpecCal 仍需依靠 MCTS 探索从零补全新结构，其成功率取决于基础模型的自回归补全能力——而这一能力在弱基座上可能同样有限。论文对 CoCa 的探索增益归因较乐观，但未量化探索失败的样本比例。
- **超参数迁移性**：$C=1.5$ 在全部实验中固定，虽然展示了鲁棒性，但未讨论不同数据集或基座模型下最优 $C$ 的差异；$\lambda$ 和温度的敏感性分析仅针对 NIST，其对 SynSet 的适用性未经验证。
- **评估粒度的缺失**：没有按分子复杂度（如重原子数、官能团数量）或光谱特征（如峰重叠程度）对性能增益进行分层分析，因而无法判断 SpecCal 在哪些“光谱模糊性最严重”的样本上提升最大或失效。若补充该分析，将为“光谱模糊性”这一核心动机提供更直接的证据。

## 9. 可能的改进方向与未来工作

- **更高效的搜索机制**：用可学习的策略网络替代纯启发式 UCB 选择，或对 MCTS 的扩展阶段引入批量并行化、剪枝策略，以降低推理时延。也可将搜索历史跨样本共享，避免每次测试独立冷启动。
- **更强的光谱一致性奖励**：采用多个 IR 预测器的集成，或在奖励中融合其他模态约束（如 MS、NMR）与化学价约束；使用扩散模型或基于物理的 IR 仿真器（如量子化学计算）作为奖励模型的补充，以减少 Chemprop-IR 系统误差。
- **面向任意分子空间扩展**：将分子约束放宽至更大重原子数、带电物种、立体异构体，并探索 SpecCal 在聚合物、无机物或混合物光谱解析上的适用性。
- **与生成模型协同训练**：将 SpecCal 的搜索过程蒸馏回基础模型的解码策略，使模型在推理时直接偏好光谱一致性更高的结构，或在 beam search 初始阶段即注入 MCTS 获得的候选边缘分布，实现训练—推理闭环。
- **系统化的替代方案对比**：与多样化 beam search、对比解码（contrastive decoding）、频谱后处理匹配（如库检索）等方法在统一评价体系下对比，明确 SpecCal 的增量价值。
- **不确定性量化的深入利用**：当前熵仅用于选择替换位置，可扩展为对整条 SMILES 的全局不确定性估计，指导多步连续编辑或自适应迭代次数分配。

## 10. 总结与关键启示

SpecCal 的核心贡献在于将 IR-to-molecule 任务的重心从“训练更好的生成模型”转向“测试时优化候选集”，并为此提供了一个免训练、模型无关、可插拔的校准框架。其关键启示可归纳为四点：

1. **光谱模糊性是任务的内在难点，而非模型缺陷**——任何基于似然解码的生成模型都难以仅凭单次解码绕过该歧义，测试时显式地按光谱一致性搜索是对该问题的合理补充。
2. **前向光谱预测器是高质量奖励的来源**——利用预训练 IR 预测器（Chemprop-IR）反推分子与光谱的一致性，比依赖化学式匹配等粗糙信号有效得多，且无需额外标注。
3. **“重排序 + 探索”是互补的**——重排序解决了“好结构排位靠后”的问题，探索解决了“好结构从未生成”的问题；二者结合才能同时提升 top-1 与 top-10 指标。
4. **多样性是准确率的盟友而非敌人**——SpecCal 展示出通过适当设计的 MMR 选择，提升候选集多样性并不会牺牲精度，反而能显著扩大覆盖真实结构的概率。

总体而言，SpecCal 是 IR-to-molecule 测试时计算（test-time computation）方向的一个扎实工作，方法简洁、实验完整、分析多维。其不足在于推理开销较大、分子空间受限、替代基线缺失，但其“用搜索补偿模糊性”的思路对同类逆问题（如 MS/MS、NMR 结构解析）具有启发性，后续工作可在此基础上进一步优化效率与扩展性。
