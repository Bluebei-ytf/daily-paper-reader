## 摘要
许多分子动力学模拟旨在研究两种状态（从反应物到产物）之间的转变。在此背景下，提交者函数（对于给定的分子构型，给出在反应物状态之前到达产物状态的概率）是一个关键量，特别是因为它是稀有事件模拟方法（如重要性采样或分裂技术）的最优重要性函数。这些方法用于采样反应路径系综，并估计例如转变速率。然而，由于构型空间的高维度，学习这样一个函数通常是一项具有挑战性的任务。在本工作中，在回顾了构造近似提交者函数的现有方法之后，基于伊藤公式的应用提出了一种新的损失函数，通过神经网络参数的极小化过程来学习提交者函数。在将这种新方法与现有方法在Müller-Brown势上进行比较后，我们引入了一种与自适应多级分裂方法相结合的耦合策略，以通过更好地采样反应轨迹来更精确地逼近提交者函数。这种迭代学习提交者函数的方法仅需要初始时了解反应物和产物状态。

## Abstract
Many molecular dynamics simulations aim at studying transitions between two states (from reactants to products). In this context, the committor function (which gives for a given molecular configuration the probability to reach the product state before the reactant state) is a pivotal quantity, in particular because it is the optimal importance function for rare event simulation methods such as importance sampling or splitting techniques. These methods are used to sample the reactive path ensemble, and estimate for example the transition rate. However, learning such a function is generally a challenging task due to the high dimensionality of the configuration space. In this work, after reviewing the existing methodologies to construct approximate committor functions, a new loss function based on the application of Itō's formula is proposed to learn the committor function with a minimization procedure on the parameters of a neural network. After comparing this novel approach to existing procedures on the Müller--Brown potential, we introduce a coupling strategy with the Adaptive Multilevel Splitting method to better approximate the committor function using a better sampling of the reactive trajectories. This methodology in which the committor function is iteratively learned only requires initially the knowledge of the reactant and product states.
