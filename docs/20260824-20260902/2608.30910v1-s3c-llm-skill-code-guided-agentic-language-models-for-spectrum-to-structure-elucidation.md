## 摘要
光谱结构解析是分子分析的核心任务，但当前基于大语言模型（LLM）的方法大多将其视为直接的谱图到SMILES生成问题。尽管这一范式能够利用配对的光谱数据，但它并未显式建模光谱学家所用的分析流程，例如诊断峰解释、碎片推理、分子式约束以及化学一致性检查。在本文中，我们提出了S3C-LLM，一种技能引导且基于代码的智能LLM，用于谱图到结构解析。S3C-LLM不直接预测分子，而是检索针对模态的光谱技能，执行分析代码以在输入谱图上实例化这些技能，并在生成SMILES前整合所得的峰级证据与分子式约束。具体而言，我们贡献了一个自进化的光谱技能库、一个思维增强的技能-代码轨迹构建流程，以及一个两阶段训练策略，该策略通过监督微调（SFT）和随后提出的逐步强化学习（RL）来训练Qwen3-4B。在多个基准上的实验表明，S3C-LLM在各种谱图上始终优于当前通用LLM及光谱专用模型，而训练语料仅为SpectraLLM的十分之一以下。

## Abstract
Spectroscopic structure elucidation is central to molecular analysis, but recent Large Language Model (LLM)-based methods mostly formulate it as direct spectrum-to-SMILES generation. Although this paradigm can leverage paired spectral data, it does not explicitly model the analytical workflow used by spectroscopists, such as diagnostic peak interpretation, fragment reasoning, formula constraints, and chemical consistency checking. In this paper, we introduce S3C-LLM, a skill-guided and code-grounded agentic LLM for spectrum-to-structure elucidation. Rather than directly predicting a molecule, S3C-LLM retrieves modality-specific spectroscopy skills, executes analysis code to instantiate these skills on the input spectra, and integrates the resulting peak-level evidence and formula constraints before generating SMILES. Specifically, we contribute a self-evolving spectroscopy skill library, a thinking-augmented skill-code trajectory construction pipeline, and a two-stage training strategy that teaches Qwen3-4B through supervised fine-tuning (SFT) followed by our proposed step-level reinforcement learning (RL). Experiments on diverse benchmarks show that S3C-LLM consistently outperforms current general LLMs and spectrum-specific models across spectra, while using less than 1/10th of SpectraLLM's training corpus.

## 2. 方法论

### 2.1 总体框架

- 输入为经峰级文本化表示的光谱 \(x\)，输出为目标分子 SMILES \(y\)。
- 推理过程表示为轨迹 \(\tau=\langle S, c, o\rangle\)：
  - \(S\)：检索到的光谱技能；
  - \(c\)：生成的可执行分析代码；
  - \(o\)：代码执行输出。
- 学习目标从 \(p_\theta(y|x)\) 改为 \(p_\theta(\tau,y|x)\)，即最终预测显式依赖技能和代码证据。
- 构建流程分三步：技能库自进化、Agentic轨迹合成、两阶段训练。

### 2.2 技能库构建（Self-Evolving Skill Library）

- 定义模态相关的技能模板，覆盖八种模态/技能文件：IR、Raman、UV-Vis、¹³C NMR、¹H NMR、HSQC、simulated NMR、MS/MS。
- 使用外部 LLM Agent（Claude Opus 4.6 + Claude Code）进行“预测–验证–诊断–修订”循环：
  - 对每种模态运行 20 轮进化，每轮用 50 个训练集光谱；
  - 根据当前技能预测 SMILES，检查官能团/碎片/分子式线索是否与参考结构一致，再增删修正规则。
- 技能以 Markdown 形式保存“峰区→官能团”“碎片/中性丢失→候选结构”等可复用分析规则，并刻意只保留确定性高或高置信度的规则，模糊关联不写入。
- 附录展示的 HSQC、MS/MS 技能文件表明，技能库包含化学位移区间表、CH 多重峰、中性丢失表、诊断碎片表、化学合理性打分规则等。

### 2.3 Agentic 数据构建

定义两个工具：

- `read_skill(name)`：按模态读取对应 Markdown 技能；
- `run_code(code)`：执行自包含 Python 分析代码，返回结构化证据。

轨迹形式：
- 单模态输入：一次 `read_skill` + 一次 `run_code`；
- 多模态输入：多个并行 `read_skill`，再用一次 `run_code` 聚合分析；
- 工具调用包裹在 `<tool_call>` 中。

构建规模：
- 共合成 **500K 条 instruct 模式轨迹**；
- 再用 GPT-5.4 反向生成“思考痕迹”（thinking traces），要求思考内容逐步分析谱图、解释技能、概括代码输出并推导 SMILES；
- 用同一模型进行“只看思考不看参考动作”的重预测，过滤掉与参考答案不一致的轨迹，得到约 **100K 条含显式思考的轨迹**；
- 其余 400K 轨迹保留空 `<think>` 块以统一训练格式。

### 2.4 两阶段训练

- **第一阶段：SFT**
  - 在 500K 轨迹上全参数微调 Qwen3-4B；
  - 对空思考块进行 loss masking，避免模型学习无意义思考。
  - 目标函数为掩码 token 级交叉熵：
    \[
    L_{SFT}=-\sum_{(x,\hat\tau,y)\in D}\sum_{j=1}^{|z|} m_j\log p_\theta(z_j|x,z_{<j})
    \]
    其中 \(m_j=0\) 跳过空思考 token，否则为 1。

- **第二阶段：Step-level RL**
  - 在 20K RL 轨迹上使用 GRPO（Group Relative Policy Optimization）变体；
  - 先做初步 rollout 和去重，再按“assistant action step”分解技能检索、代码执行、最终结构预测；
  - 分步奖励：
    - 技能检索步骤：技能是否与输入模态匹配；
    - 代码执行步骤：Python 是否无错误执行；
    - 最终结果：按 Morgan 指纹 Tanimoto 相似度计分；
    - 错误工具调用、缺失技能、执行失败、非法 SMILES 给 0 奖励。
  - 每个 rollout 第 \(t\) 步的 reward-to-go：
    \[
    G_{i,t}=\sum_{k=t}^{T_i}\gamma^{k-t}r_{i,k}
    \]
  - 在同一 prompt 组的同一步骤索引上标准化为优势：
    \[
    A_{i,t}=\frac{G_{i,t}-\mu_{g,t}}{\sigma_{g,t}+\epsilon_{norm}}
    \]
  - 使用 clipped 策略目标对 assistant token 段优化，并允许下游结构预测奖励反向传播到早期的技能检索与代码执行步骤。
  - 不采用显式 KL penalty；相比轨迹级单一奖励，step-level 能区分“工具执行正确但最终预测错误”等异构失败情况。

## 3. 实验设计

### 3.1 数据集 / Benchmark

- **QM9S 单光谱任务**：Raman、UV-Vis、IR；
- **Multimodal Spectroscopic Dataset**：¹³C NMR、¹H NMR、HSQC、MS/MS，以及“¹³C+¹H+HSQC”联合设置；
- **MassSpecGym**：实验 MS/MS 谱；
- 所有谱图转换为紧凑的峰级文本表示；
- 训练/测试划分沿用 SpectraLLM 的 splits；训练分割限制所有使用参考结构的合成步骤，评估分子/谱图不参与。

### 3.2 对比基线

- **通用 LLM**：GPT-5.5、Gemini-3.1-Pro、DeepSeek-V4 Pro、Claude-Opus-4.7，直接做谱图→SMILES；
- **光谱专用模型**：IR-to-Structure、Spectra2Structure（QM9S）；Spec2Mol、DiffMS（MS/MS）；NMR2Struct（联合NMR）；SpectraLLM（多个对应场景，采用论文报告结果）。
- **评估指标**：RDKit 计算的 Tanimoto、cosine、MACCS Tanimoto、Fraggle 相似度；强调以结构相似性而非精确匹配为主，因为单谱图可能不唯一确定结构。

### 3.3 主实验结果

- **光学谱（QM9S Raman/UV-Vis/IR）**：S3C-LLM 在所有三个单光谱设置上均全面优于光谱专用基线和 SpectraLLM。例如 Raman Tanimoto 0.3354 vs SpectraLLM 0.2500；IR Tanimoto 0.2534 vs SpectraLLM 0.1921。
- **MS/MS**：在 Multimodal Spectroscopic Dataset 上优势显著，S3C-LLM Tanimoto 0.6382 vs SpectraLLM 0.1844；在 MassSpecGym（带噪实验谱）上同样领先，但优势更小（0.1832 vs 0.1533），与“模拟谱可被代码精确做分子式筛选、实验谱噪声大”的预期一致。
- **NMR**：单模态（¹³C、¹H、HSQC）及三模态联合均优于 SpectraLLM。联合设置下 S3C-LLM Tanimoto 0.5021 vs SpectraLLM 0.4151。
