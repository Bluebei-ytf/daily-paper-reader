## 摘要
优化吸收、分布、代谢和排泄（ADME）是小分子药物发现的重要部分。许多机器学习模型已被用于预测ADME属性以促进这一优化过程，但解释模型预测具有挑战性。我们提出了一种新的图神经网络架构，具有内建的、有意义的逐原子归因。我们的模型MolLedger输出的预测是逐原子分数的总和。MolLedger的加性框架在不牺牲性能的情况下获得了精确的可解释性，因为全局上下文向量为加性头提供了足够的上下文来产生良好的逐原子分数。此外，MolLedger生成的归因比其他可解释性方法更忠实于化学属性，因为MolLedger中的辅助损失将原子分数锚定到化学属性上。我们的案例研究比较了多种方法在分子对上的解释，结果表明MolLedger在生成对预测属性变化的合理解释方面明显更好。

## Abstract
Optimizing absorption, distribution, metabolism, and excretion (ADME) is an important part of small molecule drug discovery. Many machine learning models have been built to predict ADME properties to facilitate this optimization process, but explaining model predictions is challenging. We propose a new graph neural network architecture with built-in meaningful per-atom attributions. Our model MolLedger outputs predictions that are the sum of per-atom scores. MolLedger's additive framework obtains exact interpretability at no cost to performance because the global context vector gives the additive head enough context to produce good per-atom scores. Furthermore, MolLedger produces attributions that are more faithful to chemical properties than other interpretability methods because the auxiliary loss in MolLedger anchors the atom scores to chemical properties. Our case studies comparing interpretations from multiple methods on molecular pairs reveal that MolLedger is much better at producing sensible explanations for predicted property changes.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 在**小分子药物发现的先导化合物优化阶段**，化学家需要反复修改候选分子上的基团，以改善吸收、分布、代谢、排泄（ADME）相关性质。传统做法依赖湿实验，成本高且耗时；机器学习模型可用作虚拟筛选工具，加速这一过程。
- 尽管已有大量用于 ADME 预测的机器学习模型（包括图神经网络 GNN），但**模型预测的可解释性不足**是一个关键瓶颈。化学家在决定是否信任模型预测、选择哪些分子进入下一轮筛选时，难以获得有意义的结构—性质关系指导。
- 已有的可解释性方案存在明显缺陷：
  - **事后解释方法**（LIME、Grad-CAM、集成梯度 IG、遮挡法 WISP 等）：其逐原子归因不一定反映原子对预测标签的真实数值贡献，也可能与物理化学性质不一致。
  - **注意力方法**（如 LigandFormer）：注意力权重仅反映“关注程度”，不反映归因方向或数值大小，且不直接等同于预测贡献。
  - **广义加性模型（GAM）类方法（如 GNAN）**：严格加性约束导致预测性能明显下降，且其原子加性项不完全对应物理性质。
- 论文的核心问题是：**能否设计一种图神经网络，使预测精确等于逐原子分数的加和，同时这些原子分数有明确的化学意义、且不牺牲预测精度？**
- 提出的答案是 **MolLedger**：一种将加性输出、全局上下文向量与化学属性锚定辅助损失相结合的 GNN，旨在同时满足“精确可解释”“化学上有意义”“预测性能不损失”三个目标。

## 2. 论文提出的方法论

### 2.1 核心思想
MolLedger 的预测输出被严格构造为各原子分数之和：

\[
\hat{y} = \sum_{i=1}^{N_{\text{atoms}}} s_i
\]

其中每个原子分数 \(s_i\) 不是仅由该原子自身的特征决定的，而是可以依赖整分子的信息（经由消息传递和全局上下文向量），从而克服了经典 GAM 在表达能力上的限制。

### 2.2 关键技术细节

**（1）加性原子分数 + 全局上下文向量**
- 底层使用 4 层 GINEConv 消息传递模块（含批归一化和 ReLU），生成每个原子的表示 \(A_i\)。
- 原子表示先经**求和池化**和**平均池化**，拼接后通过一个 2 层 MLP（\(\phi_2\)）生成**全局上下文向量**。
- 全局上下文向量被拼接到每个原子表示上，再经另一个 2 层 MLP（\(\phi_3\)）计算每个原子的分数 \(s_i\)。
- 公式如下：
  \[
  \hat{y} = \sum_{i=1}^{N_{\text{atoms}}} \phi_3\left(A_i,\ \phi_2\left(\sum_{i=1}^{N_{\text{atoms}}} A_i,\ \frac{1}{N_{\text{atoms}}}\sum_{i=1}^{N_{\text{atoms}}} A_i\right)\right)
  \]
- 该设计使模型在输出层面满足严格的加性可解释性，但每个原子分数头吸收了整分子上下文，从而保留全局预测能力。

**（2）锚定辅助损失（auxiliary loss）**
- 研究者指出：仅约束原子分数之和等于预测值，存在无穷多种分解方式，因此需要额外的化学约束。
- MolLedger 在训练中为每个任务选择一个化学“锚点”（anchor），即每个原子的某种物理化学性质：
  - **Crippen score**：经验分子疏水性分数（原子 logP 贡献），用于锚定 logD、肝脏清除率、溶解度和血浆蛋白结合率等相关任务（方向可为正或负，取决于性质与疏水性的相关性）。
  - **拓扑极性表面积 TPSA**：用于锚定 Caco2 通透性和外排比等相关任务。
- 辅助损失为每个分子每个任务计算归一化偏差的均方误差：
  \[
  L = \frac{1}{\sigma_y^2}(y-\hat{y})^2 + \frac{\lambda_{\text{anchor}}}{N_{\text{atoms}}}\sum_{i=1}^{N_{\text{atoms}}}\left(\frac{s_i-\bar{s}}{\sigma_s} - \text{sign}_{\text{anchor}}\frac{a_i-\bar{a}}{\sigma_a}\right)^2
  \]
- 即：强制原子分数相对于分子的分布模式（均值/标准差归一化）与锚属性的分布模式一致，方向由任务的化学相关性决定（正号或负号）。
- \(\lambda_{\text{anchor}}\) 在 {0.1, 0.3} 中调节；不带锚定的消融实验（\(\lambda=0\)）用于评估该辅助损失的有效性。

**（3）分子对与局部化评估**
- 采用匹配分子对（Matched Molecular Pair）策略：通过 rdkit 的片段索引算法识别共享核心、仅有一个取代基不同的分子对。
- 定义“泄漏”（leakage）指标：变化中被归因于共同核心而非被替换基团的比例——越好的解释应把性质变化主要归因于发生化学修饰的基团。

## 6. 论文的主要结论与发现

1. **加性约束不损害性能**：
   - MolLedger 的全局上下文向量弥补了纯加性模型在表达力上的不足。与 Pooled GNN 相比，MolLedger 在 logD、动力学溶解度和 Caco2 A-to-B 上的 MAE 和 Spearman 相近甚至更优。
   - GNAN 的严格加性模型在上述任务上存在明显的性能退步，说明加性框架下全局上下文是关键。

2. **锚定损失显著提高化学忠实度**：
   - 带锚定的 MolLedger 在 faithful（与 Crippen/TPSA 的相关性）指标上远超未锚定版本以及所有事后方法。
   - 锚定损失不损害排序能力或分子对差异的预测能力（多数任务），尽管在小鼠/人肝清除率上单分子 MAE 略有上升，但配对 Δ MAE 不变。

3. **精确性（exactness）优势**：
   - MolLedger 的精确性缺口为 0；IG 和 LIME 接近精确但有偏差；Grad-CAM 精确性差；WISP 的逐原子归因无法加和到预测。

4. **局部化存在固有的性能—可解释性权衡**：
   - 将性质变化完全归因于取代基（而非核心）对所有任务都很困难，除了 logD。
   - 无上下文的模型和 GNAN 泄漏更少，但预测性能明显更差——这表明泄漏并不完全代表解释缺陷，也可能是模型捕捉了跨片段相互作用的真实信号。

5. **案例研究表现**：
   - 在 logD、动力学溶解度和肝清除率的分子对案例中，MolLedger 对性质变化方向的归因最为合理。
   - 事后方法（IG、Grad-CAM、LIME、WISP）在同一模型上产生相互矛盾的归因，说明事后方法可靠性差；
   - GNAN 因无法感知邻居原子身份而在关键极性原子归因上出现系统偏差。

## 7. 优点

1. **创新性地解决“可解释性与精度不可兼得”的矛盾**：
   - 在不同子层引入了全局上下文向量，使输出层具有原子加性形式而不牺牲分子级表达能力；这是一个简洁而有效的架构设计。

2. **第一性原理的归因约束**：
   - 用 Crippen 分数和 TPSA 作为原子级锚点并设计归一化偏差损失，给出一个明确的化学先验注入框架；可在不同 ADME 任务上灵活调整锚定方向。

3. **精确可解释性（exact interpretability）**：
   - 归因由构造保证加和为预测值，避免了事后解释方法在归因与预测不一致时的不可靠性。

4. **实验设计贴近真实药物化学实践**：
   - 引入匹配分子对和泄漏指标，用取代基对核心的归因“泄漏”程度来评价解释定位能力，比纯分解精度检验更进一步。

5. **推理开销极低**：
   - MolLedger 的归因计算与预测本身同量级（0.0888 ms/分子），显著优于 IG（约 90×）、LIME（约 40×）和 WISP（约 540×），实用性强。

6. **提供全面开源实现**，代码已在 GitHub 公开，便于复现与社区应用。

## 8. 不足与局限

1. **锚点的适用范围有限**：
   - 只使用了两个锚属性（Crippen 疏水性和 TPSA），并非所有 ADME 任务都适合这些锚；半衰期甚至因方向不明确未锚定。对有复杂代谢机制的清除率、对转运蛋白底物识别等场景，锚属性可能过于简化。
   - 论文也在附录 D 中承认，在部分人肝清除率案例中锚定甚至起了误导作用（锚属性无法解释环化减少代谢的机制）。

2. **“忠实度”指标的刻度偏置风险**：
   - 自带锚定损失的模型天然更容易与锚属性相关；将该模型与没有锚定机制的事后方法比较时，忠实度差距大并不完全等价于“更化学上合理”。论文没有提供化学家主观评估研究。

3. **泄漏指标的价值有一定争议**：
   - 作者自己也指出低泄漏与高精度的权衡可能不可完全避免；因此泄漏低不一定代表解释好，泄漏高也不一定代表解释差——这削弱了该指标作为严格解释质量标准的可判定性。

4. **小规模任务统计功效不足**：
   - 一些任务测试分子数量很低（如 n<100 的半衰期、血浆蛋白结合等），且未给出置信区间估计；结论外推性有限。

5. **数据合并带来的标签不一致风险**：
   - 将多个数据库合并时仅做了简单换算（如 Caco2 的单位转换），不同实验方案、测定平台之间的系统偏差未被充分讨论，可能导致模型学习到数据来源伪相关。

6. **案例展示的选择性偏倚**：
   - 正文中展示的是变化最大、差异最清晰的分子对；这些是有利于解释方法的“最佳场景”，可能高估模型在实际筛选中的解释质量。对中等差异分子对的系统评估不足。

7. **与最新 ADME 模型的比较有限**：
   - 虽然对比了 GNAN、LigandFormer、附加描述符模型等，但没有与一些较新的预训练大模型（如大规模分子预训练模型、近期ADME专用模型）比较，性能排序的时效性有限。

8. **仅针对回归任务**：
   - 论文明确排除了二元分类任务（如人肠道吸收），限制了方法的适用范围。
