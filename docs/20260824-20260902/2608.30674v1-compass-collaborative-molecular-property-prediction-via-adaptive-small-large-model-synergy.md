## 摘要
准确的分子性质预测既需要统计可靠性，也需要化学推理。图神经网络可以直接在标记测定数据上进行校准，但仍受限于其训练数据的覆盖范围。大型语言模型（LLMs）能够比较分子证据并阐述化学原理，但作为独立的定量预测器并不可靠。因此，核心挑战在于确定LLM何时应影响校准模型，以及影响程度有多大。在此，我们提出了CoMPASS，一个用于小-大模型协作的检索校准框架。CoMPASS保留图注意力网络（GAT）作为预测锚点，检索局部相关的训练分子，向LLM提供基于注意力的证据，并通过一致性感知门控将其提议转化为有界修正。在六个分类基准和两个回归基准上，CoMPASS在可纠正不确定性区域提升了GAT锚点的性能，同时限制了高置信度区域中LLM的干预。消融研究表明，性能提升源于验证校准的检索和有界融合，而非单纯的提示。这些结果表明，生成式推理应通过基于证据的、受控的修正来增强校准预测，而非直接替代输出。代码可在 https://github.com/littlepeachs/CoMPASS 获取。

## Abstract
Accurate molecular property prediction requires both statistical reliability and chemical reasoning. Graph neural networks can be calibrated directly on labeled assays but remain limited by the coverage of their training data. Large language models (LLMs) can compare molecular evidence and articulate chemical rationales, yet are unreliable as standalone quantitative predictors. The central challenge is therefore to determine when an LLM should influence a calibrated model and by how much. Here we present CoMPASS, a retrieval-calibrated framework for small-large model collaboration. CoMPASS retains a graph attention network (GAT) as the predictive anchor, retrieves locally relevant training molecules, provides attention-grounded evidence to an LLM, and converts its proposal into a bounded correction through an agreement-aware gate. Across six classification and two regression benchmarks, CoMPASS improves the GAT anchor in regions of correctable uncertainty while limiting LLM intervention in high-confidence regimes. Ablations show that the gains arise from validation-calibrated retrieval and bounded fusion rather than prompting alone. These results suggest that generative reasoning should augment calibrated prediction through evidence-grounded, controlled corrections rather than direct output replacement. Code is available at https://github.com/littlepeachs/CoMPASS.

### 1. 核心问题与整体含义（研究动机与背景）

分子性质预测是药物发现和毒理学中的基础任务，其数值输出的可靠性直接关系到下游的筛选、优先级排序和风险评估决策。论文指出这一任务存在"双重需求"：

- **统计可靠性**：预测器需要在有标签的测定数据上进行严格校准；
- **化学推理能力**：当局部数据稀疏或模糊时，模型需要能对化学证据进行推理。

**两类模型的固有缺陷**：
- **图神经网络（GNN/GAT）** 能够直接在标记数据上监督学习，其预测经过校准，但可靠性受限于训练数据分布的覆盖范围。在决策边界附近、稀有骨架、稀疏活性区域或任务嘈杂的场景中，可能产生过度自信的错误预测。
- **大语言模型（LLMs）** 能够进行化学文本推理、比较分子、阐述化学原理，但作为独立的定量预测器并不可靠——流畅的化学理由并不等于校准过的定量预测。

**核心问题**：何时应让 LLM 影响一个经校准的预测模型，以及影响的程度应多大？

**整体回答**：论文提出 CoMPASS 框架，将 LLM 的生成式推理视为一种**受控的修正机制**（controlled correction），而非直接替换小模型的输出。这种方法实现了"统计可靠性与化学推理"的互补结合。


### 2. 方法论：核心思想、关键技术细节与算法流程

**总体框架**：CoMPASS 分解为四个阶段，GAT 始终充当预测锚点，LLM 的介入被严格约束。

**阶段①：GAT 产生监督预测与证据**
$$\hat{y}_s, c_s, a_s, h_s = f_s(G)$$

输出包括：预测值、置信度、注意力权重和分子图表征。
- 分类任务的置信度为预测锐度：$c_s = \max(\hat{y}_s, 1-\hat{y}_s)$
- 回归任务的置信度由 MC-Dropout 不确定性转化：$c_s = \frac{1}{1+u_s}$

**阶段②：检索校准的基础预测（Retrieval-Calibrated Base Prediction）**
这一阶段最核心的设计创新，它赋予检索双重角色：
1. 为 LLM 提供提示证据（prompt evidence）；
2. 通过验证集拟合的加权聚合方式，产生一个独立的数值校准估计。

相似度度量融合三种信号：
$$\text{sim}(i,j) = \omega_m m_{ij} + \omega_q q_{ij} + \omega_a r_{ij}$$
- Morgan 指纹重叠、图嵌入余弦相似度、注意力重叠

检索校准预测：权重归一化后加权聚合检索分子的标签得到 $\hat{y}_r$，基础预测为 $\hat{y}_b = (1-\lambda)\hat{y}_s + \lambda\hat{y}_r$，其中 $\lambda$ 通过验证集搜索确定最优值。**这使得检索不仅是提示上下文，还起到验证校准的数值修正作用。**

**阶段③：结构化 LLM 提案**

向 LLM 输入一个包含以下内容的提示包：目标分子 SMILES、GAT 预测与置信度、注意力突出显示的功能基团、检索分子及其标签与 GAT 预测、冲突汇总等。LLM 返回数值提案 $\hat{y}_\ell$、建议门控 $g_\ell$ 和推理理由 $r_\ell$。解析失败时回退到小模型预测。

**阶段④：一致性感知有界门控（Agreement-Aware Bounded Gate）**

$$g = \text{clip}(s_{\delta_{\ell r}} \Phi_\Theta(g_\ell, e_s),\; f_{\delta_{\ell r}},\; c_{\delta_{\ell r}})$$

门控值由多个信号决定：
- **归一化不确定性**：分类使用熵，回归使用 dropout 不确定性
- **检索冲突** $\rho = \text{std}_{j \in R_K(s)}(y_j)$，衡量检索邻域内标签的一致性
- **注意力一致性** $A_s$：目标分子与检索分子的注意力重叠平均相似度
- **方向一致性**：当检索迁移方向 $\Delta_r$ 与 LLM 提案方向 $\Delta_\ell$ 一致时给予最大的门控上限；弱一致时中等上限；不一致时最小上限

最终融合公式为：
$$\hat{y} = (1-g)\hat{y}_b + g\hat{y}_\ell$$

**推理流程（单分子七步）**：运行 GAT → 检索计算 $\hat{y}_r$ → 形成 $\hat{y}_b$ → 提示 LLM → 解析 LLM 输出（失败回退）→ 计算一致性与门控 → 输出融合值并保留完整审计痕迹。

### 6. 主要结论与发现

1. **LLM 的正确角色是"受控修正"而非"输出替代"**：CoMPASS 多数数据集上提升了 GAT 锚点性能（BACE +0.096、BBBP +0.080、ClinTox +0.044、HIV +0.040），但收益集中在可修正的不确定性区域。

2. **检索是主要信号载体，门控是控制阀**：消融显示单独"LLM+GAT"几乎无提升（0.756 → 0.759）；加入检索校准后显著改善；加入注意力证据和有界门控后达到最优。检索信号的数值贡献大于 LLM 推理本身。

3. **检索大小是验证校准轴**：不同数据集的最佳 K 值不同（BACE/ClinTox/Tox21 需 K=6，其他多为 K=8），说明 K 不是装饰性超参数，而是决定 LLM 看到"聚焦的局部反事实集"还是"更嘈杂的邻域摘要"的设计轴。

4. **置信度分层的修正规律**：低置信 GAT 预测修正收益最大；高置信区间的过度修正风险最大，因此 LLM 的影响必须封顶。

5. **框架具有模块可替换性**：LLM 骨干可从 Llama-3-8B 换成 Qwen2.5-7B、ChemDFM、ChemLLM 而保持增益；GAT 锚点可替换为 GraphGPS 图 Transformer，接口依然有效。

6. **验证了协作方法在低余量场景中的安全性**：在 CYP450（GAT 已很强 +0.003）等低余量数据集，保守门控保护了锚点性能不倒退。

- **门控信号设计合理**：将"检索方向"与"LLM 方向"的一致性作为门控核心变量，配合检索冲突与注意力一致性共同控制修正幅度，形成可解释的多信号决策机制；最终预测可明确分解为四个显式信号来源（小模型、检索邻域、LLM 提案、门控值），而非"黑箱混合"。
