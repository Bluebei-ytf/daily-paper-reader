## 摘要
多步逆向合成规划旨在通过一系列可行反应将目标分子分解为商业可得的构建模块。即使对于专业化学家来说，庞大的组合搜索空间也使得这项任务具有挑战性。传统方法将树搜索与离线训练的价值网络相结合，这些网络孤立地对候选物进行评分，而不考虑完整的多步路线。近期的工作利用大语言模型（LLM）处理此任务，但依赖于简单的接口，限制了对完整搜索空间的探索。我们引入了RetroAgent，一个通过具有结构化记忆的“缰绳”来桥接符号搜索与神经推理的LLM智能体。通过记忆和化学工具，智能体能够观察完整的搜索状态，包括已探索的路线、可用的替代方案以及中间体的性质，从而基于全局进展和领域知识做出明智的决策。在分布内和分布外基准上的实验表明，RetroAgent具有强大的性能和泛化能力。

## Abstract
Multi-step retrosynthesis planning seeks to decompose a target molecule into commercially available building blocks through a sequence of feasible reactions. The vast combinatorial search space makes this task challenging even for expert chemists. Traditional methods combine tree search with offline-trained value networks that score candidates in isolation, without reasoning about complete multi-step routes. Recent work leverages Large Language Models (LLMs) for this task, but relies on simple interfaces that limit exploration of the full search space. We introduce RetroAgent, an LLM agent that bridges symbolic search and neural reasoning through a harness with structured memory. Through memory and chemistry tools, the agent observes the full search state, including explored routes, available alternatives, and properties of intermediates, enabling informed decisions grounded in both global progress and domain knowledge. Experiments on in-distribution and out-of-distribution benchmarks demonstrate that RetroAgent delivers strong performance and generalization.

### 主要结论与发现

1. **性能领先**：
   - 在 **USPTO-190**：Pass@1 达 **53.26%**（Retro-R1 仅 50.00%），预算 N=500 时成功率达 85.05%（PDVN 为 92.11%，但搜索方法与预算利用不同）。
   - 在 **ChEMBL-1000**：Pass@1 达 **73.82%**（Retro-R1 68.52%），预算 N=500 时成功率 84.40%，超越所有 baseline，包括 PDVN（80.60%）。
2. **RL 训练必要性**：零样本模型仅 4.42% Pass@1，确认 RL 是提升关键。
3. **关键设计**：多扩展（multi-expand）贡献最大（+12 分），深度惩罚进一步改善长路线的质量。
4. **行为分析**：训练后智能体学会在深度和广度间平衡，优先扩展含有构建模块的候选反应，工具使用中记忆工具占主导，化学工具使用迅速减少。
5. **泛化能力**：分布外 ChEMBL-1000 上优势明显，说明学习方法学到了可迁移的规划策略，而非记忆特定模式。

### 优点

- **方法论创新**：将 LLM 智能体与结构化记忆（AND-OR 图）结合，环境自动维护状态一致性，智能体专注于探索策略，实现符号搜索与神经推理的有效桥接。
- **高效的训练设计**：
  - 使用 **GSPO** 策略优化，无需 critic，降低复杂度。
  - 采用 **Truncated Importance Sampling** 提高样本效率。
  - 利用 **预过滤**（循环检测、重复反应）和 **构建模块注释** 减少无效动作。
  - 奖励塑形有效平衡搜索预算和路线深度。
- **实验严谨性**：多种消融、奖励敏感性、行为分析、失败分析等全面验证了设计选择的关键性，并排除了基座模型差异的干扰（同骨干对比）。
- **表现优异**：在更小的 4B 模型上超越 7B 的 Retro-R1，且使用更少训练数据（20K vs. 全部 ~300K 路线），展示出数据效率和泛化能力。

### 不足与局限

- **实际合成实用性有限**：实验仅验证了模板有效性和路径可行性，未考虑反应产率、区域/立体选择性、保护基策略、实验条件等实际因素，生成的路线不一定是最实用的。
- **推理成本较高**：相比传统搜索方法（如 Retro*），RetroAgent 每次调用 LLM 推理代价高，单条轨迹需数十次 LLM 调用，不适用于高通量筛选场景。
- **比较公平性问题**：
  - 与 PDVN 等搜索方法比较时，预算定义相同但实际搜索空间利用方式不同（RetroAgent 每次扩展平均 1.71 个反应，PDVN 全部顶格应用 50 个），导致高预算下 PDVN 优势更大。
  - 部分 baseline 成绩直接从原文引用，未完全复现（除 Retro-R1 已复现）。
- **分布外评估局限性**：ChEMBL-1000 虽具药物相关性，但可能与训练集存在重叠或混淆因素（如分子复杂度），文中虽量化了支架新奇性，但仍可能存在隐式相关。
- **单步模型限制**：基于模板的模型依赖预定义模板库，可能错过无模板覆盖的有效反应。此外，所有方法均使用相同单步模型，但不同方法对模型错误的鲁棒性可能不同。
- **奖励设计敏感性**：奖励权重和惩罚幅度需要调参，虽有敏感性分析，但未讨论对收敛稳定性和避毒性的影响。
- **未与最新生成式 planner（如 AOT*）比较**：文中仅对比了 Retro-R1 和传统方法，未纳入 AOT* 等近期 LLM 引导搜索方法。
